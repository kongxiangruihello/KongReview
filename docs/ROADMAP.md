## v3.5 — HTML 源码编辑

统一所有正文编辑入口为原生等宽 HTML 源码编辑器，支持标签插入、即时同步、原生撤销和动态高度。兼容旧 Markdown，打开未编辑不改写；补齐快速录入按语、成长内容、填空卡标签保护，以及 HTML 正文搜索和小结导出。

## v3.6 — 编辑检查、重复对照与正文历史

输入停顿后查重，红色提示放在正面标题右侧；并排比较重复卡片，确认后追加答案。源码模式检查常见HTML写法并提供显式修正预览。正文历史保留最近100个版本，恢复到草稿后再保存，进度保持当前值；即时草稿恢复继续可用。增加独立图形验证窗口，仅使用内存示例库与临时草稿目录。

## v3.7 — 查找替换、差异标记与资料检查

当前字段支持⌘F、字面查找、区分大小写、单处替换和全部替换预览，采用后可撤销。对照按段落标记新增、删除和改动；格式清理预览可选字体、颜色、空段落和冗余标签；链接／媒体检查验证写法、本地存在及页内目标，定位地址后手动修复。远程网站不联网测试，超长文字采用有界比较，超过5000处匹配时要求缩小范围。

## v3.8 — 录入与长文整理

带格式粘贴提供保留／清理／纯文字预览和默认选项记忆；正文与快速录入识别末尾作者、书名及页码，先核对再填写表单。标题目录支持 H1—H6、回到顶部和原编辑位置。媒体可预览并按单次引用替换，独立内容名不覆盖共享媒体。正式资料分批检查链接写法和本地媒体，暂停继续、搜索、分类与50项分页；处理前重读条目，旧库恢复清除检查会话。
