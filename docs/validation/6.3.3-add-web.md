## 做法

网页存档的阅读页已删，原样恢复会把网页存到看不见的地方。按现在的用法（作者 6.0.4 时说“我的全部摘录里存了很多文章”，今日标注从摘录里的长文抽篇），改为：

- 打开网页、提取正文（仍用原来的 `WebArticleFetcher`，即 Readability），整篇存为**一条摘录**。
- **出处**：是这个网页（类型“网页”，标题、作者、网址）。按网址认出处，找不到就新建，不按标题并入同名的书。
- **不重复**：同一网址下已有整篇正文（正文相同，或已有一条满 1000 字的长文）就不再存，提示“以前已存过”。
- **存后**：打开这个出处，并提示存了多少字、是否进入“今日标注”。正文满 1000 字（`AnnotateSettings.minimumRawLength`）的进入待标文章，按录入先后轮到。
- **入口**：加号菜单“添加网页…（⌘L）”（侧栏两个“＋”同一个菜单），以及“文件 → 添加网页…”（⌘L）。面板仍自动填入浏览器当前页面或剪贴板里的网址。
- 删去设置里失效的 `kongreview://save` 说明；使用说明、README、ROADMAP；版本 6.3.3。
