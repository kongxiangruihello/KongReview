## 依据

KongFolio 的数据格式取自其仓库（kongxiangruihello/KongFolio，main b3391d9）：`ReadingJournal.swift`（`ReadingRecord`、`ReadingEssay`、`ReadingJournalState`，存在资料文件夹的 `ReadingJournal/catalog.json`，用默认 `JSONEncoder` 写出，日期为自 2001 年起的秒数）、`Board.swift`（`SourceRef` 的页序与印刷页码）、`ReadingRecordExport.swift`（导出 Markdown 的写法）、`WorkspaceStore.swift`（资料文件夹默认在 `~/Library/Application Support/KongFolio`）。KongReview 只读这些文件。

## 实现范围

- `KongFolioImport.swift`：只解码用得着的字段（多字段、缺字段都不影响）；摘录、有文字的图片摘录 → 摘录；笔记、整本书心得 → 札记（摘的原文另作摘录挂上）；札记 → 札记（引用的摘录与阅读记录里同一条共用来源键）；导出 Markdown 的解析（`## 题目`、`> 原文`、出处行、`标签：`，去掉反斜杠转义，按内容摘要去重、只增不改）。
- `KongFolioDatabase.swift`（迁移 v27 `kongfolio_item`）：一个事务导入；按来源键去重；KongFolio 修改时间更晚则更新；KongReview 里删去的跳过；同出处同页同文的已有摘录直接对上；新札记 7 天后第一次出论证题。
- `KongFolioStore.swift`：自动导入（随收件箱检查：启动、回到前台、每分钟；catalog.json 的修改时间与大小变了才读，后台读文件），有新内容时提示；“从文件导入…”（catalog.json、阅读记录备份、导出的 Markdown，可多选）。
- 设置“数据 → KongFolio 的阅读材料”（开关默认开、位置、立即导入、从文件导入、已导入条数、上次结果）；菜单“文件 → 从 KongFolio 导入 / 从 KongFolio 文件导入…”；使用说明“附：KongFolio 的阅读材料（6.0.6）”；README、ROADMAP。
