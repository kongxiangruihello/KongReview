## 实现范围

- **卷尾再考**：卷面上答“忘了”的摘录题、论证题，判“需重读”的复述题，常规的题答完后再出，答对过关，没过的排到后面，至多两轮；不记入掌握度，两天后的补考照旧。依据：连续再学习（Rawson、Dunlosky 等，2013）。
- **常错的题一键处理**：成绩册“常错的题”每道旁有“今天再考”，摘录另有“做成记忆卡”“弃置”；“全部今天再考”。
- **每天考多久**（设置，默认不限）：按补考 → 记忆卡 → 札记 → 笔记 → 问题 → 其余摘录的次序分配，超出的顺延；“再考 10 分钟”。
- **我的回答**：要点题、出处题展开前可先写下来。
- **录入预设的起始内容（HTML）**：正面、背面、背面栏目与字段各有“起始内容（HTML）…”：左边代码框（等宽，不把直引号换成弯引号，“插入”在光标处插入）、右边即时预览；下方“新卡片的样子”按卡片样式把正面、背面与栏目合起来预览。新建卡片与“保存并新增”时先填进去；原样没改不算填写，设了必填仍须填写。存进学习库、导出导入时去掉脚本、内嵌框架、事件属性与 javascript: 链接；一栏至多 64 KB。批量录入不带起始内容。菜单“考场 → 记忆卡录入预设…”可直接打开预设管理。
