# 4.1.2 札记进笔记本、到 Obsidian

2026-10-22。在作者的 Mac（macOS 27.0.1，Swift 6.4，arm64）上从分支 `claude/v4.1.2-notes-integration`（0fcdb6f，基于 main b515aa1）全新下载、编译并运行测试。界面检查使用"KongReview预览"（内存示例库）。

## 实现范围

- 迁移 `v19-notebook-note-blocks`：`notebook_block.noteId`（札记彻底删除时置空）。
- 专题笔记本中的札记块：插入条与空笔记本的"札记…"；块内显示札记最新题目与正文（`[[链接]]` 只留文字）、所引摘录数与出处；札记被彻底删除后保留加入时的正文。导出：新的导出单元 `essay`（Markdown、RTF、网页、Word 按普通段落输出，所引摘录出处作脚注接在最后一段末尾，不用脚注时写在括号里；演示稿作文字页），HTML 正文按段落拆开；所引摘录参加引文核对与参考文献表；不重复计入写作量。札记页右栏"收入专题"。
- 编辑札记时输入 `[[`（或【【）在正文下方列出札记题目：繁简归一匹配、以输入开头的在前、最多 8 条，题目不存在时给出"新题目"；↑↓、回车或 Tab、Esc（关闭后同一处不再弹出）。
- Obsidian 同步：札记写在"札记"子文件夹，一条一个文件，文件名即题目（去掉文件名不允许的字符，同名加序号）；`[[题目]]` 改写为对方文件名（繁简不同也能对上），文末列出引用的摘录与出处；改题目或删除后，只清理带 `kongreview-note` 标记的旧文件；札记改动后自动安排同步。
- 记忆卡：由摘录做成的卡显示答案后，提示"原摘录用在札记中：《…》"。
- 修正：完整备份恢复时按备份中已完成的迁移判断版本（须为本机迁移序列的前缀），与该版结构核对后恢复再补跑迁移。此前只认最新结构，3.16–4.1.1 生成的完整备份会被拒绝。
