# 4.1.0 札记与双向关联（4.1 第一步）

2026-10-21。在作者的 Mac（macOS 27.0.1，Swift 6.4，arm64）上从分支 `claude/v4.1.0-idea-notes`（6cc6ce3，基于 main 879ad31）全新下载、编译并运行测试。界面检查使用"KongReview预览"（内存示例库）。

## 实现范围

- 新表 `idea_note`、`idea_note_highlight`、`idea_note_link`（迁移 `v17-idea-notes`），`writing_log` 增加 `noteId`。
- 正文中的 `[[题目]]` / `[[题目|显示文字]]` 链接（核心包 `WikiLinks`）：题目去空白、繁简与全半角归一后匹配；指向尚未建立的题目显示为"（未建）"，点击即新建同名札记；改题目时，指向它的链接一并改写；新建题目后原先"未建"的链接自动接上。
- 札记页：阅读/编辑两态（⌘↩ 完成）；引用摘录可调整顺序、打开、移除；侧栏显示反向链接、本条链接到、可能相关（按正文与摘录的二字组 TF-IDF 相似度）。
- 入口：侧栏"写作与产出·札记"；回顾卡 Z 键或灯泡按钮"记札记"；按语下"发展为札记"（按语原样保留）；摘录编辑面板"发展为札记…"并列出引用它的札记；回顾卡上提示"你曾在札记中用过它"。
- 与已有功能衔接：札记可归入研究项目（项目材料、写作量、当前项目回顾加权都计入）；全局搜索新增"札记"一类；学习小结表 1 增加"新写札记（条）"；写作量按"同一札记同一天合并"记账。
- 删除走软删除，可在"已删除"中恢复或彻底删除；彻底删除时去掉项目关联。
