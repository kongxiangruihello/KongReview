# 6.3.2 日课上的记忆卡、摘录用原来的编辑窗口

2026-11-10。作者来信（附记忆卡学习页截图，右上角为“编辑”“暂停”两个图标）：“在前面的版本中，我曾经让你为记忆卡和摘录增加编辑功能，但实际上编辑功能原本就有，你增加的还不如原来的好，可以继续用原来的编辑功能吗”。

## 起因

6.2.1 在日课每道题的标题行加了“编辑这道题”（⌘E），弹出一个 HTML 源码框加即时预览的面板（`ExamEditSheet`）。记忆卡、摘录本来各有完整的编辑窗口，6.2.1 却另做了一个简化面板：

- **记忆卡**：学习页右上角“编辑这张卡”（E），即 `store.editCard`。窗口有录入预设、富文本工具栏、背面栏目、修改对照与修改历史。
- **摘录**：摘录列表里的编辑，即 `store.edit`。窗口有出处、位置、译文、版本页码、关联记忆卡。

## 实现范围

- **记忆卡题**：标题行右边改为“编辑这张卡”（图标与学习页相同，⌘E），调用 `store.editCard(c)`，打开原记忆卡编辑窗口。
- **摘录题**：改为“编辑这条摘录”（⌘E），调用 `store.edit(h)`，打开原摘录编辑窗口。
- **保存后的刷新**：两个窗口保存时都会刷新资料库（`revision` 加一）。日课看到后，按 id 重新取这道题（`examRefreshed`），内容有变就换上新的。题的标识只看排程（次数、遗忘、到期），所以仍是同一道题，展开与否、“我的回答”都不动。删去了的题则不动卷面。
- **札记、笔记、问题**：它们的原编辑处在各自页面，打开要离开日课，所以仍用 6.2 的“编辑这道题”面板。面板的存取代码保留，原有测试 `V620ExamEditTests` 照旧。
- 使用说明、README、ROADMAP；版本 6.3.2。
