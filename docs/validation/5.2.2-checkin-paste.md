# 5.2.2 打卡天数与直接粘贴

2026-11-03。在作者的 Mac 上从分支 `claude/v5.2.2-checkin`（702b2c5）全新下载、编译并运行测试，一次通过。界面检查使用“KongReview预览”（内存示例库）。

## 实现范围

- 打卡：今日检查中至少做完一组（应做为 0 的组做了 1 条也算；跳过的组不算），并保存日评；两者先后不限，打了不撤销。是否“做完一组”记在当天的计划里（`plan.groupDone`），之后不撤销。
- 天数：连续（今天打了从今天数，没打从昨天数；休息日没打跳过）、最长连续（今天没打不算断）、累计、本月、本年。连续为 0 时显示本月天数。首页“学习足迹”、回顾页顶部、回顾统计、今日功课右上角改用打卡。
- 休息日：每周至多一天，按生效日期记在 `app_progress`（`checkin.restDays`），改设置不改写过去。
- 补签：每月 2 次，最近 3 天（不含今天），当天须有检查记录（今日检查已做、回顾或记忆卡、重温、自测之一）；记为 `makeup`。
- 中断原因：连续为 0 时，取最后一次打卡后第一个既没打卡、也不是休息日的日子；近 7 天内且未记原因才问；记在 `streak_break`。复盘第一步新增“打卡（天）”。
- 热力图：一年，深浅按自评，旧记录灰，补签空心，休息日浅灰；悬停显示完成、掌握、自评与一句话。
- 晚间提醒：默认 21:00，还没打卡才提醒，打卡后撤掉当天的；未来 7 天逐日排单次通知。早晨的回顾提醒不变。
- 迁移 v24：5.2.2 之前有回顾或记忆卡记录（不含只写按语）的日子记为 `legacy`，不含升级当天，已打卡的不改。
- 粘贴：带格式的内容直接按原格式粘贴，随后照常识别末尾出处；直接粘贴不成时（编辑内容已变）退回选择界面，内容不丢；设置“摘录”页可改回每次先选择。
- 日评“推进”计入当天的小胜。
