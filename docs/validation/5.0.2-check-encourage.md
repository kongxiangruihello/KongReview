# 5.0.2 检测与激励

2026-10-23。在作者的 Mac 上从分支 `claude/v5.0.2-check-encourage` 全新下载、编译并运行测试。界面检查使用"KongReview预览"（内存示例库）。

## 实现范围

- 迁移 `v21-progress`：`self_test_log`（自测记录）、`progress_event`（小胜）。升级时已解决的问题、已被链接的札记、已被引用过的出处记为不显示的底账（`quiet = 1`）。
- 每周自测（侧栏“自测”、首页“本周进展”卡、每周复盘第一步的提示）：10 题，出处题、要点题、论证题交错；题目从收藏、写过按语、被札记引用或属当前项目的摘录（有出处、未弃置、未做成记忆卡）与引用了摘录的札记中抽，要点题须有位置或按语作线索；近 28 天测过的不抽，从未测过的在前，同一周抽出的题不变（周 key 定序）。先想再展开，自评记得、大致、忘了；同一题重评以最后一次为准。做完列出忘了的：做成记忆卡、多出现、打开札记、再做一次。
- 学问检视（月度、年度复盘第一步）：自测“记得”比例、记忆卡保持率、本期修订的札记、每条平均引用与被链接、本期解决数与平均用时、各状态问题数、半年未改未重温的札记、半年未新录未回顾的出处；与上期同期比较。年度可导出“这一年的学问”（Markdown）。
- 小胜：问题有了线索（由待研究变化时，含挂上第一条材料与重温“有新线索”）、解决（每个问题只记一次）、札记修订（随修订历史，每天一次）、札记第一次被另一条链接、第一次在札记中引用某本书、自测从“忘了”到“记得”。首页“本周进展”卡、复盘第一步“本期进展”、今日功课做完时的“今日收获”、问题页右栏“经过”。
- 连续学习中断时，首页“学习足迹”显示“本月学了 n 天”而非“连续学习 0 天”。
