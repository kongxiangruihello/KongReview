# 5.0.0 重温

2026-10-23。在作者的 Mac 上从分支 `claude/v5.0.0-revisit` 全新下载、编译并运行测试。界面检查使用"KongReview预览"（内存示例库）。

## 实现范围

- 迁移 `v20-revisit`：`idea_note_review`（札记排程）、`idea_note_revision`（修订历史）、`question_review`（常念问题轮流）、`revisit_log`（重温记录）。升级时给现有札记与常念问题排第一次重温：写成不满 7 天的在写成后第 7 天，更早的分散在之后 30 天内；常念问题分散在之后一周内；升级当天不来。
- 札记重温：间隔 7、21、60、180、365 天，之后每年一次。仍然这么看→间隔加长；要修订→打开札记、从头算；以后再说→一周后再来、间隔不变。保存时题目或正文（按纯文字比较）改变→从头算，并记下改动前的一版（同一天只记一次，写成当天不记）。已删除的札记不来。
- 常念问题：只有标「常念」且待研究、有线索的来，每个约每周一次。有新线索→挂上勾选的新摘录、记的一句带日期写进说明末尾、待研究改为有线索；写解答→打开问题；还没有→下周再来。
- 每天至多 2 条札记、1 个问题（设置“回顾”页可改，0 为不重温）；处理过的（含“以后再说”）占当天名额。
- 今日功课第三步：首页功课条显示“3 重温”与合计时长（约 1 分钟一张）；“开始今日功课”依次进入回顾、记忆卡、重温；回顾完成页、记忆卡学完页、牌组首页有“今日功课第三步：重温”。侧栏“今日”组新增“重温”与剩余张数。
- 重温页：札记先见题目、空格展开正文与所引摘录；上次重温以来新录、用词相近的摘录（相关摘录索引的余弦相似度）可一键引用；1、2、3 作答，E 打开札记或问题；写一句时单键快捷键失效。
- 学习小结表 1 新增“重温札记（条）”（本期处理过的札记，去重）。
- 重温不写入 `review_event`。
