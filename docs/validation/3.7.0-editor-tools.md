## 真实桌面交互

- 在文字编辑器点击查找，输入 `world`，匹配 `WORLD` 并显示1/1。打开全部替换预览，确认仅当前字段1处改变；采用后正面变化，背面保留。点击正文执行⌘Z，恢复原文。
- 正文获得焦点后按⌘F可打开当前字段查找。源码模式也可用⌘F；用“替换此处”把 `WORLD` 替换为中文，周围HTML标签保留。
- 对带有span、strong、字号、颜色、链接及本地图片的正文，文字模式查到2处Alpha。预览并采用替换后，Gamma替换正确，Beta粗体和媒体保留。
- 格式清理预览能看到原来的大号红色文字与清理后的常规字号／颜色；粗体、链接、媒体、text-align保留，空span和空段落移除。查看源码确认，再采用，回到源码执行⌘Z可一次恢复。
- 资源检查识别缺少协议的链接、存在的本地图片和缺失的本地图片。定位缺失图片后只选中地址；粘贴替代地址，其他正文及标签保留。
- 从文字模式检查链接后，自动切换源码，选中example.com并恢复输入焦点；无需再次点击正文即可修正为HTTPS，链接文字保留。
- 编辑示例卡的背面，在已保存的保留开头／待删除段落／保留结尾之间删除中间段并追加新段。修改对照中删除段落显示红色、新增段落显示绿色；改动段落的橙色分类由自动模型检查覆盖。
- 720点窄窗口下，独立查找面板居中且所有字段与按钮完整可见；工具菜单收为紧凑图标。

- 80段长文在文字／源码模式查找末尾标记，自动滚动并显示匹配；查找使用独立子面板，源码标题离开可见区域后面板仍可输入。切换查询可返回开头。末尾全部替换预览、采用和一次撤销均通过。

## 范围

查找只作用于当前字段；源码模式会匹配标签与属性，文字模式只匹配正文。超过5000处匹配时全部替换需缩小范围。格式清理逐项选择并预览采用，代码块不自动清理。预览不执行内容脚本或加载远程资源。链接检查验证写法和页内目标，媒体检查本地存在，不联网测试远程网站／图片／音频是否在线。差异按正文段落比较，媒体和排版变化可关闭文字差异查看；超长文本采用区块比较。
