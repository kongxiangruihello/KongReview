## 完成范围

1. **五类内置录入模板**：提供名词解释、历史事件、人物、史料分析、论述题。示例只供预览，复制后正面、背面、字段及栏目正文为空白；用户修改并保存后才进入个人预设，之后可作为牌组默认录入模板。每次复制生成独立标识，修改个人副本不改变内置模板。
2. **填写提示与必填规则**：普通正反面、多字段与自定义栏目分别设置提示和可选必填。提示与规则只存在编辑上下文，不插入Card正文；缺少内容时在标题旁显示提醒，正式保存再次校验。空白HTML不算已填写，合法图片与音频可作为内容。栏目规则按卡片栏目ID绑定，重排不串位；必填栏目不能直接删除。应用模板时保存规则快照，恢复草稿沿用该快照；连续录入保留结构时重绑定新栏目ID，关闭结构沿用时不带旧规则。笔记类型、字段顺序或数量变化时拒绝误用，保留当前输入；旧版没有规则的预设和草稿继续可读。
3. **批量粘贴问答**：支持表格／Tab分列及“问：／答：”分组。表格解析保留引号内换行、Tab及双引号转义；问答支持多行答案。每批最多500张，超限不截断保存。指定每列对应后按30张分页检查，可编辑、预览、移除或取消勾选候选。非空列必须分配，不能把多列映射到同一目标而覆盖文字；必填及可显示正面均校验。内容、对应、牌组、标签或勾选变化后要求重新检查，候选修改不写回粘贴原文。正式保存事务重新读取预设、笔记模板、卡片与媒体身份，复核正面查重、必填和选择；一条失败则整批卡片及录入日志回滚。关闭尚未保存的本批输入前确认，返回原文重新拆分前说明候选修改会清除。
4. **今日录入与录入历史**：持久记录从3.11起通过录入流程新建的卡片，按原录入日期查看，每页50张，可预览、编辑及批量调整牌组或标签。历史跨重启保留，不回填旧卡，也不把导入、已有卡编辑或评分计为新录入；已删除卡片不作为当前可见条目，恢复后仍归原录入日期。新建卡片与日志在同一事务保存，失败不留下孤立记录。历史随完整备份保存，兼容v13、v14及v15；旧备份恢复后不凭现有卡片创建时间推算录入记录。
5. **批量组织操作撤销**：本次录入清单与录入历史中的移动牌组、添加／移除标签，提供当前运行期间最后一次成功组织操作的撤销。只回退此次涉及的牌组或标签变化，保留无关标签、正文与学习进度；不接管编辑器内文字撤销。相关字段已变化、卡片已删除或恢复、目标卡片正在编辑等情况拒绝覆盖，保留撤销凭据并说明原因。新操作替换旧撤销入口，成功撤销只可使用一次；完整备份恢复后清理旧会话。
