## 实现范围

1. **待回顾、待学习改为朱红**：`ReviewPalette.pending` 由藤黄改为朱红（浅色 #D93A2B，深色 #FF6A5C）；首页状态标记为实心红底白字，待回顾／待学数字、牌组页数字、卡片页计数、回顾页“记忆卡待学”数字大于 0 时为红色。
2. **本期焦点**（专题笔记本或出处，存于 `app_progress` 的 `learning.focus`）：全库回顾抽样时焦点摘录权重 ×3；学习记忆卡时焦点卡片在同类（复习／新卡）中优先；牌组卡片显示“焦点 N”，推荐牌组优先含焦点卡的；学习小结表 4 列焦点的摘录回顾、新增、按语、卡片学习进度。专题删除后焦点自动失效。
3. **回顾与记忆卡互补**：已熟记（复习间隔 ≥ 21 天）卡片对应的摘录在回顾中权重 ×0.3；近 7 天“重来” ≥ 3 次的卡片，原摘录以“重读原文”红色横幅排在当天回顾最前（最多 3 条，3 天内出现过的不再安排）。
4. **按语计入成果**：成长指标新增“写按语（条）”；编辑面板新写或改写按语时记录 `note` 事件（不计入回顾数）。
5. **学习质量（表 2）**：记忆卡保留率（只算评分前已是复习状态的卡）、反复重来的卡片、回顾筛选率（本期回顾过的摘录中，收藏／弃置／写按语至少一项者，同一条只计一次）、摘录转卡率。
6. **今日功课**：首页一条“① 回顾 → ② 记忆卡”与合计时长（回顾每条约 30 秒＋卡片估计），一键开始；回顾完成后按钮接续“今日功课第二步：学习记忆卡”。
7. **本期札记导出**：学习小结“导出”菜单中，本期收藏或写过按语的摘录按出处、位置汇总为 Markdown，附译文与按语。
