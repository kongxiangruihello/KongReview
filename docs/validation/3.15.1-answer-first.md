# 3.15.1 先作答再对照：点按钮才出现参考答案

2026-10-20。作者反馈：勾选“先作答再对照”后，参考答案在作答前就已出现（截图中“我的回答”为空、右侧已显示参考答案）。

## 原因

此前该模式下翻面仍由底部“显示答案”按钮及空格键触发；新卡出现时光标不在回答框内，此时按下空格（含输入法确认、习惯性按键）即翻面，参考答案在作答前就显示出来。

## 修改

- `CardSelfAnswerPanel`：新增 `onReveal`，在回答框下方显示“对照参考答案”按钮（⌘↩，回答框内打字时也可用）与提示；新增 `focusOnAppear`，新卡出现时光标自动进入回答框；对照后交出键盘焦点，数字键 1–4 可直接评分。
- `StudyView`：先作答模式下底部不再显示“显示答案”，改为提示“评分按钮在对照参考答案之后出现”；空格在此模式下不翻面。开关改为 `@AppStorage("study.selfAnswerFirst")`，下次学习保持。
- `CardEntryPracticeView`（额外练习）：去掉底部“显示答案”（及空格快捷键），改用回答框下方按钮。
