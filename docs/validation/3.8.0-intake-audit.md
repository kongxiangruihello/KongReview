## 范围与行为

- 只有带HTML格式的粘贴会打开三选一预览；普通纯文本直接粘贴。文字模式去掉剪贴板脚本、事件属性和不支持的地址类型；源码模式保留直接编辑源码的用途。
- 出处识别仅填写录入表单，正式保存前不创建出处或改正式记录；复杂格式引用保留正文原样。
- 媒体替换支持图片、音频和视频，单文件最大32MB；只替换当前字段中的一个引用，预览不加载远程资源。采用后媒体独立存库，主表单保存才更新正式正文。
- 检查范围为正式摘录、卡片及模板字段、网页正文、专题文字、出处网址和成长正文；不包括草稿、历史、最近删除及外部同步目录。按扫描开始时的条目上界分批读取，扫描期间修改或处理的问题需重新检查。结果保留在当前应用会话，重启后重扫。
- 检查核对可识别链接的写法及本地媒体存在，不请求远程网站、图片或音频。复杂或不完整HTML可进入原条目“检查HTML”核对。
- 结果打开前重读当前字段，已变化／删除会提示；摘录、记忆卡、网页、出处打开原条目，专题和成长问题打开所属页面。恢复备份清除旧检查会话。
