# 3.8.1 重复提醒与编辑原卡

2026-10-19。本版接续本地3.8，测试仅使用内存数据库及临时草稿目录，未读取或修改个人学习库。

## 行为

- 普通卡片和模板卡出现重复正面时，上方“正面”右侧显示红色提醒、牌组及编辑原卡／追加答案／对照入口。整组提示位于正文滚动区域外；窄窗口把操作移到同一区域的第二行。
- 编辑原卡前同步各WebKit字段、持久保存并flush当前草稿，然后重新核对目标ID、删除状态和规范化正面；打开的是最新原卡，学习进度、牌组和标签保持当前值。成功后提示从首页草稿恢复刚才输入。
- 找不到目标、正面已改变、备份进行中、草稿持久层不可用或写入失败时，留在当前编辑器并保留输入。
- 新入口“追加答案”打开对照预览，明确点击“确认追加并保存”才写入。事务再次校验目标完整快照及重复正面，避免原卡题面已变却继续追加。成功后沿用原草稿清理与学习进度保护。
- 预览弹窗由编辑器主视图持有，待同步输入使重复提醒消失时仍可打开；同步后先重新核对重复关系，变化时在当前编辑器显示错误并保留输入。
- 编辑器字段绑定捕获草稿会话UUID；旧编辑器的延迟原文、标签、模板字段或栏目回调不能写入新打开的原卡。切换草稿也会重建编辑器内容。
- 最近删除中的重复卡先恢复，再编辑或追加；仍可选择继续新建。
