# 5.0.1 复盘

2026-10-23。在作者的 Mac 上从分支 `claude/v5.0.1-reflection` 全新下载、编译并运行测试。界面检查使用"KongReview预览"（内存示例库）。

## 实现范围

- 复盘页（侧栏“今日”组“复盘”；首页“本周复盘”卡；学习小结上方“按步骤复盘…”）：周、月、年三种，可前后翻期。
- 每周五步：① 看数字（回顾摘录、学习记忆卡、新录摘录、新写札记、重温札记、解决问题、写作，与上期同期比较）② 看新材料（本期收藏与写按语的摘录，按出处列出；记札记、挂到问题）③ 看自己的想法（本期新写、本期修订及次数、最近一次重温选“要修订”而之后未改的）④ 过一遍常念问题（本期解决的；常念的及本期新挂材料数，改状态、取消常念；最近的其他未解决问题可标为常念；超过 12 个提示精简）⑤ 写三句话（与学习小结“复盘”同一份 GrowthReflection；收获写成札记、困难记为问题（预填第一句）、下一步转为学习计划；对照上期下一步）。
- 月度同上；年度在写三句话前加“观点的变化”（今年修订过的札记，年初或初写时与现在并排），第四步另列一年的问题并可导出 Markdown。
- 任何一步可跳过；进度与完成时间存在 `app_progress` 的 `reflection.<周期 key>`；不新增表。
- 首页“本周复盘”卡：未做时显示上次复盘日期与“去复盘”，做过显示三句话；周初三天里上周未复盘则指向上周。
- 每周复盘提醒：设置“回顾”页，默认关闭；打开后默认星期日 20:00，排之后 4 次，提醒对应的那一周（提醒前一天所在的周）已复盘就跳过；完成复盘后重排。
