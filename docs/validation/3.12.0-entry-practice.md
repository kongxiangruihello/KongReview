## 实现范围

1. **批量录入草稿**：保存粘贴原文、解析格式、首行标题、字段对应、预设快照、牌组、标签、候选及其逐条修改、勾选集合、页码和候选编辑中的内容。支持自动保存及“保存草稿并关闭”，再次打开恢复；恢复后重新读取当前资料检查，不复用旧的查重结论。草稿保存失败保留窗口并说明原因；过期窗口不能覆盖较新的草稿，成功整批保存与草稿关闭在同一事务完成，防止迟到回调复活已保存的批次。明确放弃前确认，放弃仅清除此批未保存输入。
2. **个人模板管理**：复制已有个人预设形成独立预设与栏目标识，默认标签、折叠和填写规则保留。自定义栏目上下移动时，栏目及规则整体移动，不按旧位置重新分配提示。可导出单个或全部模板的独立、版本化 JSON；文件仅含录入设置，不含卡片正文、学习状态、笔记类型定义或牌组绑定。导入先预览结构与规则、选择项目及另存名称；重名项目须改名或取消，加入时生成新标识，不覆盖现有预设或绑定。缺失笔记类型、字段名称或顺序变化的项目不能导入。正式导入事务重新校验当前类型与名称，任一所选项失败则全部回滚。对格式、文件大小和项目数量设置边界，文件内容不作为脚本或排版模板执行。
3. **重复候选处理**：在重复条目旁查看原卡、编辑原卡、预览追加或跳过。编辑原卡前持久保留本批输入，并关闭批量窗口后再切换；重新打开可继续其他候选。追加遵循既有选定内容、目标位置、完整预览、正式复核与撤销流程；成功后排除此候选，再重新检查其他选择。查看、编辑和追加前重新读取原卡并核对重复关系，已删除原卡不能直接编辑或追加。
4. **录入历史衔接练习**：按单日、起止日期范围或全部日期查询，保留搜索、牌组筛选与分页。每张卡显示当前未学／学习中／已复习／暂停状态、正式作答次数以及适用的下次到期时间。当前页所选卡片可进入独立额外练习；启动时重新校验筛选、页码与卡片，练习中资料或类型变化时要求重新开始。额外练习不写正式卡片、评分日志、排程、每日名额或成长统计。
5. **先作答再对照**：正式学习及额外练习可先输入自己的回答，再翻面查看参考答案。宽窗口并排显示，窄窗口上下排列；不根据文字自动判分。正式学习保留既有评分流程；额外练习提供“还需巩固、部分掌握、已掌握”的本次自评。自己的回答和自评只属于当前会话，不进入卡片正文或正式学习记录；切换卡片时不得串到另一题。输入时避免空格、数字和编辑快捷键误触翻面或评分。
6. **摘录编辑器高度修复**：原文、译文／白话和按语使用随内容高度的编辑区，短内容不保留原固定大空白，增加与删除文字后同步增减高度。长内容使用外层窗口滚动，文字与 HTML 模式、格式工具、切换和保存前的输入同步继续保留。
