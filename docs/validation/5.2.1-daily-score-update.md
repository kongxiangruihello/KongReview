## 实现范围

- 日评（今日检查页下方）：推进、完成度、掌握度、总分四格；自评 1–5 与一句话，只能当天写或改，次日锁定；近 7 天总分。掌握度只算记忆卡（每张取当天第一次评分）、自测、笔记重温，满 5 条才算；总分按完成 40 · 掌握 40 · 自评 20，缺一项时按 70 · 30，两项都缺只看自评。
- 在线更新：读取 GitHub Releases 最新发布；比较版本号；下载 DMG（进度、速度、剩余时间，可取消、可放到后台，首页顶部显示进度）；核对大小与 SHA-256；安装前备份学习库，挂载 DMG 核对应用标识、版本与签名，复制到缓存目录；退出后由助手脚本把旧版移到 `~/Library/Caches/KongReview-updates/上一版/`、换上新版、去掉扩展属性并重新打开，复制失败时放回旧版。启动后 8 秒检查，每天至多一次（设置“更新”页可关）；菜单“KongReview → 检查更新…”；“跳过这个版本”。预览版与开发构建不能就地安装。
