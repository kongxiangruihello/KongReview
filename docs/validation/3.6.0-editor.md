# 3.6.0 编辑体验验证

2026-10-19。使用独立测试包 `com.kongxiangrui.KongReview.EditorCheck`、内存数据库和临时草稿目录；普通应用仍打开原有数据库。验证时未读取或修改个人学习库。

## 真实桌面窗口

- 重复的 `hello WORLD` 在停顿后显示红色“正面重复 · 示例牌组”，位置在“正面”标题右边。
- 通过真实按钮打开并排对照，左右显示当前输入／已有卡片的正面、背面、牌组和出处。
- 点击追加，出现确认；确认后关闭当前草稿。重新打开已有卡片，原答案和追加答案同时存在。
- 打开历史，选择旧版并恢复到编辑器；再打开修改对照，左侧为恢复的正文，右侧为尚未覆盖的正式版本。
- 将错误示例 `<a href="gemini.google.com>gemini</>` 输入源码，中文提示缺少结束引号和协议。修正预览为完整 HTTPS 链接；点击采用后源码更新，切回文字模式为链接。
- 输入100段 HTML，首段左侧完整，滚动到第100段与末尾标记完整；撤销后恢复先前的链接。
- 新增“释义”栏目，在该栏目独立切换源码并输入加粗中文，切回文字时正面和背面仍保留各自内容。
- 退出并重新打开测试程序，从草稿菜单恢复中文、标点及释义栏目。测试库重新生成后，旧草稿与原卡冲突时按既有规则恢复为新卡并提示，不覆盖已有卡。
- 在720点窄窗口检查正文、栏目、工具栏和底部操作；通过“保留草稿并关闭”确认关闭，草稿继续存在。

## 自动回归

新增检查覆盖 HTML 修正与合法属性中的 `>`、实时查重、正文历史、恢复时保留学习进度、追加答案事务和过期快照拒绝、模板背面追加、中文组合输入提交。

既有自动图形用例仍受命令行测试宿主限制而跳过；上述真实桌面检查独立记录，不计入自动测试通过数。中文粘贴、排版、恢复已在真实窗口验证，输入法的标记文字／提交路径通过原生测试；自动化键盘未能调出真实拼音候选窗口，候选窗口交互仍未验证。

HTML 检查是常见写法提示，不是完整浏览器 HTML 校验器；复杂模板、可选闭合标签需人工核对。正文历史从3.6起记录，保留最近100个版本，旧版未记录的修改无法追补。
