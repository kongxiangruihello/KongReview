# 6.3.5 补签更显眼

2026-11-10。作者来信：“特别突出一些补签功能”。

## 原来的样子

补签（5.2.2）只在成绩册最下方“打卡”一节里的一小行：小字说明，加几个日期按钮，点开才出现自评与一句话。日课首页和今日日课上只有连续中断时的一句提示，“可以在成绩册下方补签”。不翻到成绩册最下面就看不到。

## 做法

- **补签卡片**（`MakeupCard`）：有可以补签的日子时，出现在日课首页、今日日课、成绩册的最上面。卡片红框、浅红底，内容依次是：
  - 标题“11月8日 漏了打卡，可以补签”，右上角“本月还能补 N 次”；
  - 大字“补签后连续打卡 4 天（现在 1 天，多 3 天）”；
  - 几天可补时，每天一枚按钮，写着“某日 → 连续 N 天”；
  - 规则说明一句；
  - 自评五档（数字加说明）、一句话输入框、“补签 某日”按钮（选了自评才可点）。
- **补后连续天数**：`CheckinSummary.makeupStreak`，把“连续”的算法提成 `AppDatabase.currentStreak` 后，对每个可补签的日子各算一次。默认选接得最长的一天，一样长时取最近的一天。
- **其他提示**：
  - 打卡那一行加红色小标“可补签 N 天”。
  - 打卡图上可补签的日子画红色虚线框，悬停说明补后连续几天；图例加“可补签”。
  - 当天的晚间打卡提醒末尾附一句“另有某日可以补签（补后连续 N 天），在日课首页补”。
- 断掉的那天还能补签时，不再先问中断原因（补上就不算断）。成绩册下方原来的补签小行去掉。
- **规则不变**：只能补最近 3 天、当天确有日课记录，每月 2 次。
- **示例库**：前天改为“做完了但没写日评”，预览里能看到卡片。
