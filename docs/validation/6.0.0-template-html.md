# 6.0.0 卡片模板的 HTML 编辑

2026-11-03。在作者的 Mac 上从分支 `claude/v6.0.0-template-html`（773f452）全新下载、编译并运行测试，一次通过。

## 实现范围

- `NoteTemplate` 增加 `html`（正面、背面、样式）；有 HTML 时按 `CardTemplateEngine` 渲染，否则沿用放置。迁移 v25 给 `note_template` 增加 `html` 列。
- 模板写法：`{{字段}}`（花括号内可有空格）、`{{FrontSide}}`（背面不重复显示，并去掉紧随的 `<hr id=answer>`）、`{{#字段}}…{{/字段}}`、`{{^字段}}…{{/字段}}`（可嵌套）、`{{cloze:字段}}`、`{{hint:字段}}`（折叠的“显示提示”）、`{{text:字段}}`、`{{type:字段}}`（正面不显示、背面显示字段）。
- 检查：不存在的字段、条件没有收尾或多出收尾、正面用 `{{FrontSide}}`、空的 `{{}}`、不认识的写法；有问题不能保存。
- 编辑器：“放置 / HTML”切换；HTML 三栏（正面、背面、样式），等宽、不自动替换引号的代码框；字段按钮在光标处插入；“更多”里插入条件、提示、完形填空；右侧预览最多 8 张示例卡可换。切到 HTML 时由放置生成等价代码。
- 普通卡片样式：记忆卡页“卡片模板”菜单“普通卡片样式…”，存于 `app_progress`（`cards.plainCSS`）；作用于所有没有 HTML 模板的卡片。
- 卡片显示：学习页、编辑预览、草稿预览按卡片带上样式；用户样式中能跳出 `<style>` 的写法、`@import`、外部网址图片不生效。
- Anki：导入时读第一张卡片模板与样式（旧格式 `col.models` 的 `tmpls`/`css`；新格式 `templates.config` 第 1、2 字段与 `notetypes.config` 第 3 字段），模板只用到已有字段时才采用；导出时 HTML 模板的样式以 `<style>` 随正面带过去。
