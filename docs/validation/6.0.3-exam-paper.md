# 6.0.3 今日试卷

2026-11-03。在作者的 Mac 上从分支 `claude/v6.0.3-exam-paper`（e3de79e）全新下载、编译并运行全部测试，全部通过。

## 实现范围

- **一个入口**：侧栏“考场 → 今日试卷”（`SidebarItem.dailyCheck` 改显示 `ExamView`），菜单“考场 → 今日试卷”（⇧⌘R），菜单栏图标、首页“开始 / 接着答卷”、`kongreview://review`、记忆卡学完后的按钮都到这里。侧栏去掉今日检查、今日回顾、重温、自测；记忆卡（牌组、浏览、录入）移到“题库”。
- **组卷**（`ExamStore`）：摘录取当天这一组（`todayReviewSession`，与今日回顾共用 `review.session._all`；还没抽时按每天的加权抽样抽，补考排最前）；札记、笔记、问题取重温队列；记忆卡取全部牌组的下一张到期卡（每日上限照旧）。`ExamRotation` 按“记忆卡、摘录、札记、记忆卡、摘录、笔记、问题”轮转，没有题的类跳过。
- **五种题**（`ExamViews`）：作答题（正面、我的回答、背面、四档评分，`answerRecordingUndo`）；摘录题（`ExamHighlightMode`：有出处且有位置或按语的逐日在要点题、出处题之间轮换，只有出处的考出处，没有出处的给开头；记得 / 大致 / 忘了，“记得，并收藏”“记得，弃置”；记为看过并推进当天进度）；论证题（展开后先判记得 / 大致 / 忘了，再选仍然这么看 / 要修订 / 以后再说）；复述题；进展题（先写一句，再看新录的相关摘录）。
- **记录**：摘录题、论证题的作答写入 `self_test_log`（`setKey = "exam"`，同一天同一条以最后一次为准），计入掌握度；以前某天忘了、这次记得时记一件小胜。
- **补考**：`examRetestHighlightIDs`——最近一次作答为“忘了”、在昨天以前且 30 天以内的摘录，每天至多 3 道（不超过每日条数的一半）。
- **成绩单**：答完或“先交卷，看成绩单”后在卷面下方显示日评、打卡、热力图、待整理的笔记。
- **今日检查**：`dailyCheck(groups:)` 新参数，应用只传摘录、记忆卡、札记·笔记·问题三组；每周自测不再计入。
- **设置**：“考场”页改为各类每天至多出几道；去掉“每天从本周自测带几题”“每周一显示上周小结”。
- **说法**：首页功课条、摘录卡片、打卡条、提醒通知、菜单栏改为“今日试卷”“答卷”“题”。
