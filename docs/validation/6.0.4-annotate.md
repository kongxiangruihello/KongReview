# 6.0.4 每天标注文章

2026-11-03。在作者的 Mac 上从分支 `claude/v6.0.4-annotate`（93615f9）全新下载、编译并运行全部测试，全部通过；安装包 `KongReview-6.0.4.dmg` 生成并签名。

## 实现范围

- **数据**（`AnnotateDatabase`，迁移 v26）：`article_annotation`（每篇一行：在这里划了几条、第一次与最近一次划、何时标完）、`article_mark`（新摘录来自哪篇）；当天篇目存在 `app_progress` 的 `annotate.<日期>`（篇目、题目、作者、字数、抽时的篇数）。不改动、不删除已有摘录。
- **哪些算文章**：原文至少 1000 字、去掉标签至少 600 字、未删除、未弃置；在这里标过的不再抽；同一出处下已有短摘录、其文字（去标点空白后前 30 字，至少 6 字）出现在正文里的视为以前在 Readwise 等处划过，不抽（在这里从别篇划出的不算）。
- **每天抽定**：当天第一次组卷时以日期为种子随机抽 N 篇（`annotate.perDay`，默认 5，0–20，0 为不出）；同一天不变；调多了当天补足，调少了只显示前几篇；库里不够时不反复重抽。之后刷新只查标注进度，不再读正文。
- **标注面板**（`AnnotateSheet`）：复用阅读器（`ReaderWebView`），把长摘录当作文章（id 取负）打开；选中按 H 或“划为摘录”→ `addHighlight(from:)` 识别负 id → 存为同一出处下的新摘录（位置随原文）并记入 `article_mark`，正文标黄；“这篇标完了”（⌘↩）记下标完并打开今天下一篇没做的。
- **今日试卷**：题目下方“今日标注 x / N 篇”与各篇状态；`DailyCheckGroup.annotate`（按篇）计入卷面进度、完成度与打卡；首页功课条第 4 项“标注文章 待 N 篇”，每篇按约 8 分钟计入预计用时。旧接口 `dailyCheck(groups:)` 的默认值改为 `DailyCheckGroup.legacy`，不受新组影响。
- **设置**：“设置 → 考场 → 今日标注：每天标几篇文章”。
- **说明**：使用说明“一、今日试卷”加一条；README、ROADMAP（成绩册顺延为 6.0.5）。
- **预览示例库**：加 4 篇长文与 1 篇“以前划过”的长文，每天 3 篇。
