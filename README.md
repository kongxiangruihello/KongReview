# KongReview

个人用的 macOS 摘录与回顾工具。思路参照 Readwise：把读书、读网页时的摘录集中起来，每天随机推送几条，让旧摘录重新出现在眼前。

属于 kong 系列应用（kongflow · kongbabel · kongvox · kongfetch）。0.6 起由 KongGlean 更名为 KongReview：首次启动会自动把旧版的数据和设置复制过来，旧链接 `kongglean://` 继续可用。

## 6.0.7 错题回炉、每天考多久、录入预设的起始内容（HTML）

- **卷尾再考**：卷面上答“忘了”的摘录题、论证题，判“需重读”的复述题，在常规的题答完后再出一次，答对才算过关；没过的排到后面，每道至多再考两轮。两天后的补考照旧。卷尾再考不记入掌握度（掌握度只看第一次作答）。卷面顶部显示“卷尾再考 n 道”，成绩单写明过关几道。依据：连续再学习（successive relearning）——每轮提取到答对为止，再隔几天重复。
- **常错的题一键处理**：成绩册“常错的题”每道旁边有“今天再考”（放进今天的卷尾），摘录还有“做成记忆卡”“弃置”；“全部今天再考”一次放进去。
- **每天考多久**：“设置 → 考场 → 每天考多久”（默认不限）。设了时长，当天第一次组卷按补考的摘录 → 到期的记忆卡 → 札记 → 笔记 → 问题 → 其余摘录的次序分配，超出的顺延到明天；答完时可以“再考 10 分钟”。今日试卷的应做数按分到的题数算。
- **摘录题写“我的回答”**：要点题、出处题展开前可以先写下来（可不写），展开后对照。
- **录入预设的起始内容（HTML）**：录入预设里的正面、背面（以及背面栏目、笔记类型的字段）除了填写提示，还可以用 HTML 写“起始内容”，左边写 HTML、右边即时预览，“插入”里有小标题、要点列表、编号步骤、两列表格、引文、分隔线。新建卡片（含“保存并新增”）时先填进这一栏；原样没改不算填写，设了必填仍须填写。导出、导入录入预设时一并带上。

## 6.0.6 导入 KongFolio 的阅读材料

KongFolio 里读书时记下的摘录、笔记与札记导入进来，作为考题。

- **自动导入**：读取 KongFolio 的阅读记录 `~/Library/Application Support/KongFolio/ReadingJournal/catalog.json`。启动、回到前台时和每分钟看一次，文件改过才导入，有新内容时提示一句。“设置 → 数据 → KongFolio 的阅读材料”可关掉、换位置、立即导入；菜单“文件 → 从 KongFolio 导入”。
- **怎么对应**：
  - 摘录、有文字的图片摘录 → 摘录。出处取书名与作者，位置取页码（有印刷页码用印刷页码），“我的笔记”作按语，带“KongFolio”标签。
  - 笔记、整本书心得 → 札记；笔记里摘的原文另作一条摘录挂在札记上。
  - 札记 → 札记；每段引用的摘录挂上（与阅读记录里的同一条共用，不导成两条），论述正文照录。
- **出题**：摘录进入每天的抽题范围，出要点题与出处题；札记 7 天后第一次出论证题。
- **重复导入**：按 KongFolio 的编号去重；KongFolio 里改过的更新原文、按语、出处、页码或札记正文；在 KongReview 里删去的不再加回来；KongFolio 里移到“最近删除”的不导入。只读 KongFolio 的文件，不改动它们。
- **导出的 Markdown**：“从文件导入…”也可以选 KongFolio 导出的 Markdown（有原文的为摘录，只有笔记的为札记；只增不改）。
- **还不导入**：没有文字的图片摘录（只有图片）；KongFolio 里没有找到“问题簿”。
- **数据**：迁移 v27 新增 `kongfolio_item`（KongFolio 的编号 → 摘录或札记、KongFolio 那边的修改时间）。

## 6.0.5 成绩册与考场门口（6.0 第五步）

日评、打卡、回顾统计、个人成长与复盘合成一本“成绩册”；首页改为“考场门口”。设计见“KongReview 6.0 设计方案：考场”第四、七节。

- **考场门口**：打开应用先到这里，只看三件事——今天的卷子（各类还剩几题、标注文章几篇）、打卡天数、上次成绩（最近一个有记录的日子的已做 / 应做、完成度、掌握度、总分、打卡与一句话）。
- **成绩册**（侧栏“考场 → 成绩册”、菜单“考场 → 成绩册”）：
  - **周报 / 月报 / 年报**：打卡天数、完成度、掌握度、平均总分与最高的一天，都与上一期相比；各类掌握度、新加的题、标注的文章、小胜、中断原因。复盘只留“这一期一句话”；以前写的收获、困难、下一步在对应一期下方照旧显示。
  - **每日成绩**：每天一行（已做 / 应做、完成度、掌握度、总分、自评、一句话、打卡），按月翻。
  - **掌握度走势**：近 12 周，记忆卡、摘录、札记、笔记各一条线；一周不满 5 次作答不画点。
  - **常错的题**：近 90 天错了两次以上或最近一次错了的摘录、记忆卡、札记、笔记，点一道打开修改。
  - **记忆卡**：原“回顾统计”的未来 30 天复习量、保留率与各牌组统计。
  - **打卡**：一年的打卡图、休息日、补签（从今日试卷的成绩单移来）。
- **侧栏“考场”**：考场门口、今日试卷、成绩册三项。复盘、个人成长、回顾统计不再单列。
- **拿掉的旧页面**：今日检查、重温、每周自测、复盘（五步）、个人成长、回顾统计的页面代码删去，原首页的学习统计、今日一句、本周复盘卡片也拿掉。旧链接与菜单都转到今日试卷或成绩册。
- **数据**：不新增表，不删任何记录。周报月报从已有的打卡、作答、新录与小胜记录算出；一句话存在 `app_progress` 的 `gradebook.remark.<期>`。

## 6.0.4 每天标注文章

“全部摘录”里有不少整篇存进来的文章（多从 Readwise 导入，一条摘录就是一整篇、上千字），里面还没有划出要点。今日试卷每天从中抽几篇来标注。

- **今日标注**：今日试卷的题目下方一栏，列出今天的几篇（题目、作者、字数、今天划了几条），点一篇打开标注。默认每天 5 篇，“设置 → 考场 → 今日标注”里改（0–20 篇，0 为不出）；调多了当天即补足。
- **怎么标**：在打开的文章里选中要紧的一段，按 H 或点“划为摘录”，这一段就存为同一出处下的一条新摘录（位置随原文），并在正文里标黄，以后在卷子上出题；原文那条不动。看完点“这篇标完了”（⌘↩），接着打开下一篇。划过一条或点了标完，即算这篇完成。
- **哪些算文章**：原文至少 1000 字（去掉标签至少 600 字）、未删除、未弃置的摘录。在这里标过的不再抽；同一出处下已有短摘录、其文字出现在这篇正文里的（以前在 Readwise 等处划过的）也不抽。每天的篇目在当天第一次打开卷子时按日期随机抽定，同一天不变。
- **计入今日试卷**：卷面进度与今日检查多一组“标注文章”（按篇计），计入完成度与打卡；设为 0 篇时不列。
- **数据**：迁移 v26 新增两张表——`article_annotation`（每篇一行：划了几条、第一次与最近一次划、何时标完）与 `article_mark`（新摘录来自哪篇）；当天篇目存在 `app_progress` 的 `annotate.<日期>`。不改动、不删除任何已有摘录。

## 6.0.3 今日试卷（6.0 第四步）

今日检查、今日回顾、记忆卡学习、重温与每周自测合成一张“今日试卷”：一个入口、一个进度，题目交错出，一律先想、再展开对照、再判分。设计见“KongReview 6.0 设计方案：考场”第二、三节。

- **入口**：侧栏“考场 → 今日试卷”（行尾为还没答的题数），菜单“考场 → 今日试卷”（⇧⌘R），菜单栏图标、首页“开始答卷”、`kongreview://review` 都到这里。侧栏不再列今日检查、今日回顾、重温、自测；记忆卡的牌组、浏览与录入移到“题库”。
- **五种题**：
  - 记忆卡·作答题：正面 →（可写“我的回答”）→ 背面，重来 / 困难 / 良好 / 简单；与牌组学习同一套 FSRS 排程和每日学习量。
  - 摘录·要点题与出处题：有出处与位置（或按语）的逐日轮换；只有出处的考出处；没有出处的给开头几个字。记得 / 大致 / 忘了；“记得，并收藏”（F）、“记得，以后不再出（弃置）”（D）。
  - 札记·论证题：给题目想理由与依据，展开后先判记得 / 大致 / 忘了，再答“还这么看吗”（间隔 7→21→60→180→365 天不变）。
  - 笔记·复述题：已吸收 / 需重读 / 待整理（不变）。
  - 问题·进展题：先写一句现在的答案或线索，再看新录的相关摘录，有新线索 / 写解答 / 还没有。
- **组卷**：各类按自己的到期日出（摘录沿用每天的加权抽样，与按书、按篇回顾共用同一组与进度）；卷面按“记忆卡、摘录、札记、记忆卡、摘录、笔记、问题”轮转交错，某类没有题就跳过。中途离开，回来接着答。
- **补考**：卷面上忘了的摘录，两天后起优先回到卷子上（30 天内、每天至多 3 道，占每日摘录题的名额），补考记得了就不再补。
- **成绩单**：答完或“先交卷，看成绩单”，卷面下方显示日评（推进、完成度、掌握度、总分）、自评与一句话、打卡与一年的打卡图、休息日与补签、待整理的笔记。摘录题与论证题的记得 / 大致 / 忘了计入掌握度。卷子上答完一类并写下日评即打卡。
- **设置**：“设置 → 考场”里改每天各类至多出几道；“每天从本周自测带几题”与“每周一显示上周小结”已去掉。
- **数据**：不新增表。卷面作答记在 `self_test_log`（`setKey = "exam"`）；摘录记为看过（`review_event`），今天这一组的进度沿用 `review.session._all`；札记、笔记、问题照旧记在各自的重温表。旧的今日回顾、重温、自测页面代码暂留（按书、按笔记本回顾仍用今日回顾页），随成绩册（6.0.5）清理。

## 6.0.2 点一下就更新（仿 KongSeek）

- **不用再发布安装包**：菜单“KongReview → 检查更新…”或“设置 → 更新”，有新版本时首页顶部也会提示。点“立即更新”，应用在本机的源码文件夹 `~/Developer/KongReview`（第一次用时自动从 GitHub 下载）里取 main 分支的最新代码，先跑核心包与应用的全部测试，再编译、签名；核对新版本的标识、版本号与签名后备份学习库，退出、换上新版并自动重新打开。测试或编译不通过就停下，当前安装的版本不动。
- **进度**：更新窗口有进度条与六步（获取新代码、测试、编译、校验、备份学习库、安装），逐步打勾，显示“测试：已通过 352 / 778 项”“正在编译新版本（120 / 360）”与用时；可以关掉窗口照常使用，首页顶部显示进度。失败时说明原因（哪项测试没通过、哪一行编译出错、连不上 GitHub），可查看构建日志、重试。
- **说明**：检查时读 GitHub 上 `project.yml` 的版本号与 README 里比本机新的各节，在面板里列出；更新后第一次打开时显示这次更新带来的改动。
- **网络**：连不上 GitHub 时经代理——“设置 → 更新”里填的，否则用系统代理（Clash 等的“系统代理”）。
- **回退**：换下来的旧版本放在 `~/Library/Application Support/KongReview/应用备份/`（留最近三个），设置里可“回退到上一版”；也可“用本地源码重新构建”。
- **安全**：源码文件夹里自己改过、与任何已发布版本都不同的文件会让更新停下，免得覆盖；`~/Developer/KongReview` 已有别的文件时不动它。钥匙串里有“KongReview Local Signing”（或 KongSeek / KongFetch 的同类证书）时用它签名，权限更新后不丢。
- **第一次**：双击仓库里的 `安装KongReview.command`（放源码、测试、编译、备份学习库、安装）。以后都在应用里点。
- **代码**：`Tools/build-app.sh`（`--test`、`--install`）取代原来 DMG 脚本里的编译部分，`Tools/build-dmg.sh` 改为调用它。原来读 GitHub Releases 下载 DMG 的更新方式不再使用。

## 6.0.1 精简为“考场”（6.0 第二步）

6.0 起 KongReview 是一个“考场”：每天来考一次，考摘录、记忆卡、札记、问题、笔记五类材料。本版按设计方案第四节，把与此无关的功能拿掉入口、停掉后台行为；数据一律不删。

- **侧栏三组**：考场（首页、今日检查、今日回顾、记忆卡、重温、自测、复盘、个人成长、回顾统计）、题库（全部摘录、收藏、未归类、已存搜索、标签、札记、问题簿、专题笔记本）、其他（出处管理、出处、最近删除、使用说明）。题库标题旁的“＋”可新写札记、记问题、新建专题笔记本。菜单“回顾”改名“考场”，并加入“今日检查”。
- **拿掉的功能**：研究项目与当前项目（含回顾加权、卡片优先、问题簿的“按项目”）、写作统计、学习计划与本期焦点、网页存档（侧栏、⌘L、菜单栏图标、“整页存档”书签；全局搜索不再列网页）、精简提要（出处书页、重温里的书）、出处封面的编辑、篇目进度、版本页码导入、首页的去年今日、常念的问题、本周进展、今日安排与当前项目卡、列表的专题汇编与参考文献表、笔记本的 Word 与演示稿导出（保留 PDF、Markdown、复制到剪贴板）、Obsidian 同步、Readwise 导入、引文速查（菜单、快捷键、“服务”菜单项）、每周小结推送与回顾页顶部的上周小结、工具栏“资料检查”按钮。个人成长里“项目进展”“学习计划”两节与写作两行一并拿掉。
- **旧书签**：以前装的“整页存档”书签仍可点，改为把网址带进快速录入浮窗。
- **升级留存**：第一次打开 6.0.1 时，在后台把上述功能里自己写的内容（研究项目及其材料与阶段、写作记录、精简提要、网页存档、学习计划与本期焦点）各导出为一份 Markdown，再另存一份完整的数据库快照，都放在备份文件夹的“6.0.1 精简前留存 日期”里，完成后提示一次；只做一次。没有内容的类别不写文件。
- **代码**：只有舍弃项在用的界面文件直接删除（研究项目页、精简提要、去年今日与常念的问题卡、每周小结、参考文献表、引文速查）；和保留功能缠在一起的（学习计划、学习旅程、个人成长、网页存档的列表状态）先拿掉入口，代码与数据层留到做成绩册时（6.0.4）一并清理。
- **数据**：不新增表，不删任何记录；数据库迁移不变。

## 6.0.0 卡片模板的 HTML 编辑（6.0“考场”第一步）

6.0 起 KongReview 定位为“考场”：每天来考一次，考摘录、记忆卡、札记、问题、笔记五类材料，其余无关的功能逐步舍弃。设计见“KongReview 6.0 设计方案：考场”。本版是第一步。

- **HTML 模板**：记忆卡“卡片模板”里，每种笔记类型可以从“放置”切到“HTML”，分正面、背面、样式（CSS）三栏直接写，右侧用这类卡片中的一张实时预览，可“换一张”。写法同 Anki：`{{字段}}`、`{{FrontSide}}`、`{{#字段}}…{{/字段}}`（有内容才显示）、`{{^字段}}…{{/字段}}`（为空才显示）、`{{cloze:字段}}`、`{{hint:字段}}`、`{{text:字段}}`。上方的字段按钮在光标处插入 `{{字段}}`；用了不存在的字段、条件没有收尾时在下方标出，不让保存。切到 HTML 时由当前放置生成等价的初始代码；切回“放置”或“恢复默认”即不用 HTML。应用在正面下方另行显示背面，背面的 `{{FrontSide}}` 与紧随的 `<hr id=answer>` 不重复显示。
- **普通卡片样式**：记忆卡页“卡片模板”菜单新增“普通卡片样式…”，为所有没有 HTML 模板的卡片写一份 CSS（加在默认样式之后），带预览。
- **与 Anki 互通**：导入 .apkg / .colpkg 时一并读入笔记类型的第一张卡片模板与样式（新旧两种包格式都读；模板用到这类笔记没有的字段时不用，仍按放置显示）；导出到 Anki 时，HTML 模板的样式随正面带过去。
- **安全**：样式里能跳出 `<style>` 的写法、`@import` 与外部网址的图片不生效；改模板只改显示，不改卡片内容。
- **数据**：迁移 v25 给 `note_template` 增加 `html`（JSON）；普通卡片样式存于 `app_progress`（`cards.plainCSS`），随完整备份。

## 5.2.2 打卡天数与直接粘贴（5.2 第三步）

- **打卡**：今日检查中至少做完一组（应做为 0 的组做了任意 1 条也算；跳过的组不算），并保存了日评，即算打卡；打了就不撤销。今日检查页顶部显示今天是否已打卡与连续、最长、累计天数；首页“今日功课”右上角打卡后显示“今日已打卡”。
- **天数**：连续（今天打了从今天数，没打从昨天数）、最长连续、累计、本月、本年。连续中断后不显示“0 天”，改显示本月打卡几天。首页、回顾页顶部、回顾统计的“连续学习”都改为打卡天数。
- **休息日**：今日检查页下方可设每周一天（默认不设）；这天不打卡不断连续，打了照样计入。改动从当天起生效，不改写过去的连续天数。
- **补签**：每月 2 次，只能补最近 3 天内、当天确有检查记录但忘了写日评的日子；补写的日评记为“补记”。
- **中断原因**：连续断了，首页与今日检查页问一句“那天是因为——出差、生病、课多、其他”，只记录；断了超过 7 天不再问。
- **热力图**：今日检查页下方与回顾统计显示一年打卡：深浅按自评，旧记录为灰，补签为空心格，休息日浅灰；悬停看当天的完成、掌握、自评与一句话。
- **提醒**：每晚 21:00 还没打卡就提醒一次（设置“回顾”页可关或改时间）；打了卡就撤掉当天的提醒。原来的早晨回顾提醒不变。
- **复盘**：第一步“看数字”新增“打卡（天）”。
- **日评的“推进”**：当天的小胜也计入条数。
- **粘贴不再弹出选择界面**：从网页、Word 等复制的内容直接按原格式粘贴（标题、粗体、列表、链接、图片都保留），粘贴后可撤销，随后照常识别末尾的出处。想每次选择保留格式、清理格式或纯文字，可在设置“摘录”页打开“粘贴带格式的内容时先选择方式”。
- **数据**：迁移 v24：把 5.2.2 之前有回顾或记忆卡记录的日子记为“旧记录”打卡（不含升级当天），所以连续天数不因升级归零。休息日设定存于 `app_progress`（`checkin.restDays`），中断原因记在 5.2.0 建好的 `streak_break`。

## 5.2.1 日评分与在线更新（5.2 第二步）

- **日评**（今日检查页下方）：推进、完成度、掌握度、总分四格分开显示。推进统计修订的札记、有线索或写了解答的问题、收藏与弃置的摘录、标为待整理的笔记，以及当天的小胜。完成度为今日检查的已做 / 应做。掌握度只算记忆卡（每张取当天第一次评分：简单、良好为好，困难为中，重来为差）、自测（记得、大致、忘了）与笔记重温（已吸收、需重读），好记 1、中记 0.5、差记 0，不足 5 条不算。
- **自评**：1 几乎没进状态、2 勉强做完、3 平常、4 专注顺畅、5 心手相应，再写一句“今天最有收获的一点，或卡住的一点”。只能当天写或改，次日起锁定。下方列出近 7 天的总分。
- **合成总分**（写下自评后算出，只作记录，不设目标）：完成度 40、掌握度 40、自评 20；缺掌握度时完成度 70、自评 30；缺完成度时掌握度 70、自评 30；两者都缺只看自评。
- **在线更新**：菜单“KongReview → 检查更新…”、设置新增“更新”页；启动时每天至多自动检查一次（可关）。有新版本时弹出版本与改动说明，可下载并安装：显示下载进度、速度与剩余时间，可取消或放到后台（首页顶部显示进度）。下载后核对大小与 SHA-256；安装前先备份学习库，再核对安装包里的应用标识、版本与签名，退出、换上新版并重新打开；旧版移到 `~/Library/Caches/KongReview-updates/上一版/` 作后备。新版发布在 GitHub Releases（kongxiangruihello/KongReview）。5.2.0 及更早的版本没有这个功能，需要手动装一次 5.2.1。
- **数据**：不新增表；自评、一句话与掌握度快照写在 5.2.0 建好的 `daily_checkin`。

## 5.2.0 今日检查与笔记重温（5.2 第一步）

5.2 补上“评分与打卡”，分三步：本版是今日检查页与笔记重温，日评分在 5.2.1，打卡天数与热力图在 5.2.2。设计见“KongReview 5.2 设计方案：评分与打卡”。

- **今日检查**（侧栏“回顾”组第二项，行尾为还剩的项数；首页“今日功课”右上角也可进入）：一页列出今天的回顾、记忆卡、重温、自测，各组显示“已做 / 应做”和合计进度。“应做”取当天第一次统计时各组的待办，之后新到期的不追加；做得比应做多按已做计。某一组今天不想做，可在行尾“…”里跳过（不计入合计，明天照常）。
- **笔记重温**：专题笔记本里自己写的文字段落（至少 20 字）也进入“重温”。卡上先只显示笔记本、所在小标题与这一段开头几个字，合上想一想这一段说了什么，空格展开对照：1 已吸收（间隔按 7、21、60、180、365 天加长）、2 需重读（3 天后再来，间隔从头算）、3 待整理（一周后再来，列入今日检查页底的“待整理”）；E 打开笔记本。在笔记本里改过这一段就不再算待整理。新写的段落 7 天后第一次回来；升级时已有的段落分散在之后 60 天内。每天至多 2 段（设置“回顾”页可改）。
- **自测进入每日**：每天从本周 10 道自测题中带 2 题算进今天的应做（设置里可改为 0–5 题；0 即不带，每周自测照常）。
- **数据**：迁移 v23 新增 `notebook_block_review`（笔记重温排程，随段落删除）、`daily_checkin`（每天一行：应做数快照与跳过的组；日评与打卡字段在 5.2.1、5.2.2 使用）、`streak_break`（5.2.2 使用）。重温记在 `revisit_log`（kind = `block`），不进 `review_event`，回顾统计与上周小结的旧数字不变。

## 5.0.3 侧栏与首页（5.0 第四步）

## 5.0.2 检测与激励（5.0 第三步）

- **每周自测**（侧栏“自测”、首页“本周进展”卡、每周复盘第一步的提示）：每周 10 题，出处题、要点题、论证题交错；先想，再展开对照，自评记得、大致、忘了，不计分。题目从收藏、写过按语、被札记引用或属于当前项目的摘录（有出处、未做成记忆卡）与引用了摘录的札记中抽取，近 28 天测过的不抽，同一周抽出的题不变。做完列出忘了的，可做成记忆卡、在每日回顾中多出现或再做一次。
- **学问检视**（月度、年度复盘第一步）：自测“记得”的比例、记忆卡保持率；本期修订的札记、每条平均引用与被链接；本期解决的问题与平均用时、各状态的问题数；半年未改未重温的札记与半年未新录未回顾的出处。年度可导出“这一年的学问”（数字、进展、观点的变化、问题）。
- **小胜与进展**：自动记下问题有了线索或解决（解决只记一次）、札记修订（每天一次）、札记第一次被另一条链接、第一次在札记中引用某本书、自测从“忘了”到“记得”。首页新增“本周进展”卡；复盘第一步列出本期进展；今日功课做完时显示“今日收获”；问题页右栏新增“经过”。
- **连续天数**：中断后不显示“连续学习 0 天”，改显示“本月学了 n 天”。
- **数据**：迁移 v21 新增 `self_test_log` 与 `progress_event`；升级时把已有的解决、链接、引用记为不显示的底账，不会在升级当天冒出一批旧事。

## 5.0.1 复盘（5.0 第二步：反思）

5.0 起 KongReview 的核心是四件事：回顾、检测、反思、激励。这一步做“反思”：按步骤回看这一周（月、年）。

- **每周五步**：① 看数字（回顾、记忆卡、新录摘录、新写与重温的札记、解决的问题、写作，与上期同期比较）② 看新材料（本期收藏与写了按语的摘录，按出处列出，可记札记、挂到问题）③ 看自己的想法（本期新写、修订的札记，以及重温时说“要修订”还没改的）④ 过一遍常念问题（每个本期新挂几条材料；可改状态、取消常念，把最近的疑问标为常念；超过 12 个时提醒精简；另列本期解决的问题）⑤ 写三句话（收获可写成札记，困难可记为问题，下一步可转为学习计划）。任何一步都可跳过，做完点“完成复盘”。
- **月度与年度**：五步同上，数字与材料按月、按年。年度在写三句话前加“观点的变化”：今年修订过的札记，左边是年初（今年才写的取初写时）的样子，右边是现在；第四步另列一年的问题（新记、解决、仍在心上），可导出 Markdown。
- **入口**：侧栏“今日”组的“复盘”；首页新增“本周复盘”卡（未做时“去复盘”与上次复盘的日期，做过显示写下的三句话）；学习小结上方“按步骤复盘…”。周初三天里上周还没复盘的，先指向上周。
- **每周复盘提醒**：设置 →“回顾”可打开，默认星期日 20:00；这一周已复盘就不再提醒。
- **数据**：不新增表。三句话与学习小结的“复盘”是同一份；复盘走到哪一步、何时完成存在 `app_progress` 的“reflection.<周期>”中。

## 5.0.0 重温（5.0 第一步：个人学术回顾）

5.0 起 KongReview 定位为“个人学术回顾”：让读过、想过、问过的东西按时回到眼前（温故），并定期回看自己这一段的学术工作（复盘）。第一步先做“重温”。

- **今日功课三步**：首页“今日功课”从“回顾 → 记忆卡”变为“回顾 → 记忆卡 → 重温”，合计时长把重温算进去（约 1 分钟一张）；“开始今日功课”依次走完三步，回顾完成页、记忆卡学完后都有“今日功课第三步：重温”。没有到期的就不显示这一步。侧栏“今日”组新增“重温”，行尾为今天还剩的张数。
- **重温札记**：先只显示题目（一句话的论断），提示先想理由；空格展开正文与所引摘录。1 仍然这么看（间隔按 7、21、60、180、365 天加长，之后每年一次）、2 要修订（打开札记，间隔从头算）、3 以后再说（一周后再来）；E 打开札记。卡上列出上次重温以来新录、用词相近的摘录（沿用相关摘录的算法），可一键引用到札记。
- **重温常念的问题**：问题簿中标为「常念」且未解决的问题轮流出现，每个约每周一次；列出上次重温以来新录、可能相关的摘录，勾选、记一句后选 1 有新线索（挂上材料，记的一句带日期写进问题说明末尾，待研究的改为有线索）、2 写解答（打开问题）、3 还没有（下周再来）。
- **每日上限**：札记至多 2 条、问题至多 1 个（设置 →“回顾”可改，设为 0 即不重温这一类）；处理过的（含“以后再说”）占当天名额。
- **札记修订历史**：保存札记时，题目或正文（按纯文字比较）变了，就记下改动前的一版，同一天只记一次，写成当天的修改不记；改过的札记重温从头算。修订历史供 5.0.1 年度复盘“观点的变化”使用。
- **学习小结**：表 1 新增“重温札记（条）”，按本期在重温里处理过的札记计，同一条只计一次。
- **数据**：迁移 v20 新增 `idea_note_review`（札记排程）、`idea_note_revision`（修订历史）、`question_review`（常念问题轮流）、`revisit_log`（重温记录）。升级时，写成不满 7 天的札记在写成后第 7 天第一次重温，更早的分散在之后 30 天内；常念问题分散在之后一周内。重温不写入 `review_event`，回顾统计与上周小结的旧数字不变。

设计方案：《KongReview 5.0 设计方案：个人学术回顾》。4.2 书目与读书进度暂停，草稿留在 `claude/v4.2.0-reading` 分支，不合并。

## 4.1.2 札记进笔记本、到 Obsidian

补齐 4.1 设计方案中前两步留下的几项，并修正旧版完整备份不能恢复的问题。

- **笔记本中的札记块**：专题笔记本两块之间点“＋”→“札记…”插入一条札记。札记块显示札记的最新正文（正文在札记页修改，笔记本随之更新）；札记被彻底删除后保留加入时的正文。导出 Word、Markdown、网页与复制 RTF 时按普通段落输出，`[[链接]]` 只留文字，所引摘录的出处作脚注（不用脚注时写在段末括号里），并参加引文核对与参考文献表；演示稿里作文字页。札记块不重复计入写作量。札记页右栏增加“收入专题”。
- **`[[` 选题目**：编辑札记正文时输入 `[[`（中文输入法下的 `【【` 也可以），正文下方列出札记题目（繁简通搜，以输入开头的在前），↑↓ 选择、回车或 Tab 确认、Esc 取消；输入的题目尚不存在时也可直接链接。
- **札记写到 Obsidian**：开启 Obsidian 同步后，札记写在同步文件夹的“札记”子文件夹里，一条一个文件，文件名即题目，开头属性含 `kongreview-note`；`[[题目]]` 改写为对方的文件名（繁简不同也能对上），文末列出引用的摘录与出处。改了题目或删除的札记，其旧文件随之清理，只清理带标记的文件。
- **记忆卡上的札记提示**：由摘录做成的卡，显示答案后提示“原摘录用在札记中：《…》”。
- **修正：旧版完整备份可以恢复**。3.16 起每版都新增了迁移，而恢复时只认最新的数据库结构，3.16–4.1.1 生成的完整备份会被当作“来自不支持的版本”而拒绝。现在按备份中已完成的迁移确定它来自哪一版，与该版结构核对后恢复，再补跑本机迁移（3.4 的专题问题随之转入问题簿）。
- **数据**：迁移 v19 给 `notebook_block` 增加 `noteId`（札记彻底删除时置空）。

## 4.1.1 问题簿（4.1 第二步）

把散在各专题下的问题收成一本“问题簿”：一个问题可同时归入几个专题与项目，随时挂上材料，解决后可写成札记。

- **问题簿**：侧栏“研究”组新增“问题簿”，行尾为未解决的问题数。可按状态（未解决／已解决／搁置／全部）、项目、专题筛选，繁简通搜，每页 50 条，离开再回来保留筛选、页码与位置。
- **一个问题**：一句话的问题、补充说明（富文本）、状态（待研究 → 有线索 → 已解决，另有搁置）、解答（富文本，或指向一条札记）、归属（任意多个专题与项目）、材料（摘录、札记、记忆卡，每条可附“为什么挂在这里”）。挂上第一条材料时“待研究”自动变为“有线索”；标为已解决前须有解答；已解决的可重新打开。
- **「常念」**：标出常放在心里的问题，在问题簿、项目页与“挂到问题”面板中排在最前；其次是当前项目下的问题。
- **回顾时挂材料**：今日回顾按 Q（或点问号图标）弹出“挂到问题”：选一个未解问题把当前摘录挂上，可附一句说明，也可当场新建问题（可归入当前项目）。学记忆卡显示答案后同样按 Q。回顾卡片下方提示“挂在未解问题下：…”；摘录编辑面板列出挂着它的问题；札记页列出以它为解答、或挂着它的问题。
- **写成札记**：有解答的问题可“写成札记”——问题为题、解答为正文，带上挂着的摘录，归入问题所属的项目；问题的解答改为指向这条札记。札记被彻底删除时，其正文留作问题的解答。
- **与现有功能衔接**：专题页“问题与解答”改为列出问题簿中归入本专题的问题；项目页“未解问题”读问题簿（归入本项目或其专题的）；学习小结表 1 增加“解决问题（个）”，月、年复盘引导的“解决问题”改读问题簿；另增“本期札记”Markdown 导出；全局搜索增加“问题”；资料检查增加札记与问题簿。
- **迁移**：迁移 v18 新建 `question`、`question_material`、`question_scope`，并把 3.4 的专题问题（`topic-question.*`）逐条转入：归属原专题；原关联的摘录、文字或卡片转为材料；已解决的保留解决日期；问题原文有格式、多段或超过 120 字时整段留作补充说明。未保存的草稿（`question-draft.*`）转为问题簿的“未保存的输入”。转换成功一条删一条旧键，解不开的旧记录原样保留；打开数据库或恢复旧备份时也会补转。升级前自动把整个库复制到“应用程序支持/KongReview/升级前备份”。

## 4.1.0 札记与双向关联

补上“思”这一环：自己写的观点不再只能挂在一条摘录上。设计见“KongReview 4.1 设计方案：札记与问题簿”，本版是第一步，问题簿在 4.1.1。

- **札记**：侧栏“写作与产出”新增“札记”。一条札记写一个观点，题目就是观点本身（如“乾嘉考据并非一味反理学”）；正文用自己的话写；可引用任意多条摘录（可调整顺序、可移除），以引文样式显示原文与出处。删除先进入“已删除”，可恢复或彻底删除。
- **双向关联**：正文里写 `[[题目]]` 或 `[[题目|显示文字]]` 链接其他札记（与 Obsidian 内部链接写法一致），繁简、全半角、空白归一后按题目匹配；阅读时链接可点击，尚未建立的题目显示“（未建）”，点击即新建。对方改题目时，各处的 `[[旧题目]]` 自动改写。札记页右栏列出反向链接、本条链接到的札记，以及“可能相关”的未引用摘录（沿用相关摘录的用词相近算法，只作提示）。
- **从哪里写**：札记页“新写札记”；今日回顾按 Z 或点灯泡图标（引用当前摘录，也可加入已有札记）；按语旁“发展为札记”（以按语为底稿并引用这条摘录，按语本身不变），回顾卡片与编辑面板都有。
- **旧札记与新材料相遇**：回顾到被札记引用过的摘录时，卡片下方提示“你曾在札记中用过它：《…》”；编辑面板的按语下列出引用它的札记。
- **与项目、写作量**：札记可归入研究项目（札记页“项目”菜单或项目页“归入”）；当前项目的札记所引摘录计入回顾加权；写札记的字数计入写作量（来源“札记”），归入项目的计入该项目。
- **搜索与小结**：全局搜索增加“札记”一类；学习小结表 1 增加“新写札记（条）”。3.15 的“本期札记”导出改名为“本期收藏与按语”，以免与独立的札记混淆。
- **数据**：迁移 v17 新建 `idea_note`、`idea_note_highlight`、`idea_note_link`，`writing_log` 增加 `noteId`；完整备份自动包含。

## 4.0 个人学术成长：侧栏六组与首页当前项目（4.0 第三步）

4.0 把 KongReview 定位为“个人学术成长”应用：在摘录回顾与记忆卡之上，以研究项目为中心组织阅读、积累、写作与复盘。三步依次为 3.16 研究项目、3.17 写作量与本版。

- **侧栏六组**：今日（首页、今日回顾、记忆卡）、研究（在研项目、全部项目）、阅读（出处管理、网页存档、出处列表）、积累（全部摘录、收藏、未归类、已存搜索、标签）、写作与产出（专题笔记本）、成长（个人成长、回顾统计）；最近删除与使用说明在最后。各组可折叠并记住状态，出处列表与标签仍各自折叠。原有入口全部保留。
- **首页当前项目卡**：题目、类型与阶段、截止日期与剩余天数、第一条下一步（到期标红）、未解问题数、本周写作字数与天数；点题目进入项目页。没有项目时引导新建，有项目但未设当前项目时可直接选。今日功课一栏不再重复显示焦点。
- **一次性说明**：首次打开时首页显示新侧栏的说明，点“知道了”后不再出现。
- 学习小结表 1 的增减列与本期数字统一使用千分位。

## 3.17 写作量（4.0 第二步）

- **自动记录**：专题笔记本中自己写的字——“文字”“小标题”块与摘录块的“本文批注”——每次保存时比较前后字数，记入当天该笔记本的写作量（新增与删减分开累计）。摘录原文是引文，不计。撤销删除时重新插入的块不重复计。
- **字数口径**：中文（汉字、假名、谚文）逐字计，西文、数字按词计，标点、空白与 HTML 标记不计，与 Word“字数统计”的中文字数＋西文词数接近。改写时按字数增减计，同样长度的改写不计。
- **记一笔**：在 Word 等处写的稿子，在项目页“写作”一块点“记一笔”，填本次新写的字数，或填外部稿件当前全文字数（第一次只作起点，以后按与上次的差计入）。手记可删除。
- **项目页“写作”**：稿件现有字数（所归笔记本中自写的字＋外部稿件最近登记的全文字数）与目标字数进度、近 12 周每周新增柱形、写作天数、最近记录。笔记本的写作按其当前所归的项目计。
- **学习小结**：表 1 增加“写作（字）”“写作天数”两行（与上期同期比较，不可点选）；表 4 当前项目增加本期写作字数，并列出本期阶段变化。
- 只记录实际节奏，不设每日任务与连续天数。

## 3.16 研究项目（4.0 第一步）

定位调整为“个人学术成长”：在摘录回顾、记忆卡之上，新增“研究项目”作为一级对象。完整方案见设计文档（4.0：研究项目与侧栏重组），本版是三步中的第一步。

- **研究项目**：一个项目就是一件要交出去的成果——论文、著作、讲座与讲稿、课程、其他。可填研究问题、截止日期、目标字数；阶段分构思、资料、初稿、修改、已交出、完成六步，另有“搁置”，每次改动都记下日期。
- **项目页**：阶段条（点即推进或退回）、下一步（关联到本项目的学习计划，可直接新建）、未解问题（来自所归专题笔记本的专题问题，可补答或新记）、材料（所归专题笔记本与出处，摘录与卡片去重计数）、阶段记录。可归档（完成或放下）或删除；删除只删项目本身，材料都保留。
- **归入项目**：专题笔记本与出处页的工具栏新增“项目”菜单，可归入、移出或新建项目并归入；一本笔记本可属于多个项目。学习计划可关联研究项目。
- **当前项目**：3.15 的“本期焦点”改为“当前项目”，范围扩大为项目全部笔记本与出处的摘录；回顾加权 ×3、记忆卡优先、牌组“焦点 N”与学习小结表 4 照旧。升级时已设的焦点自动转成一个项目（类型“其他”、阶段“资料”）并设为当前项目。新建第一个项目时自动设为当前项目。
- **侧栏**：新增“研究项目”一组（在研项目按截止日期排列）与“全部项目”（含归档）。侧栏六组重排在第三步完成。
- **数据**：新增 `research_project`、`research_project_link`、`research_project_stage`、`writing_log` 四张表（迁移 v16）；笔记本或出处删除时自动去掉关联。完整备份为整个数据库快照，自动包含新表。

## 3.15.1 先作答再对照：点按钮才出现参考答案

- 打开“先作答再对照”后，参考答案一直遮住，直到在回答框下方点“对照参考答案”（或 ⌘↩，在回答框里打字时也可用）。空格不再翻面，避免还没作答时误按空格（或输入法确认时）把答案翻出来。
- 每张新卡出现时光标自动进入“我的回答”，可直接输入；对照后光标离开回答框，数字键 1–4 直接评分，要补写再点回回答框。
- 评分按钮在对照之后出现；“先作答再对照”的开关会被记住，下次学习仍保持打开。额外练习同样处理（原底部“显示答案”改为回答框下方的按钮）。

## 3.15 回顾、记忆卡与个人成长的闭环

- 待回顾、待学习改为醒目的朱红：首页任务卡的状态标记为实心红底白字，“待回顾”“当前待学”的标签、数字与进度条同色；牌组卡片、学习页顶部与首页明细中的待学张数也用朱红（圆点仍表示新卡／学习中／待复习）。
- 本期焦点：在个人成长“学习小结”第四节选一个专题笔记本或出处为焦点。全库回顾抽样中焦点摘录的权重为平时的 3 倍；记忆卡在同为可学时优先焦点卡片（不突破每日上限）；牌组卡片标出“焦点 N”，“开始复习”优先含焦点卡片的牌组；回顾卡片注明“本期焦点”；小结表 4 报告焦点上回顾、卡片、按语与新增摘录的进展。专题或出处删除后焦点自动失效。
- 回顾与记忆卡互补：已在记忆卡中熟记（间隔 ≥ 21 天）的摘录，在回顾中的权重降为 0.3 倍；由摘录做成的卡片近 7 天重来 ≥ 3 次时，原摘录在下一组回顾中排在最前，卡片上注明“重读原文”（最近 3 天出现过的不重复安排，每天最多 3 条，占用每日条数）。
- 按语计入成果：学习小结新增“写按语（条）”一项，可看明细与按出处／专题分布；在编辑面板中新写或改写按语也会记录（此前只记录回顾中写的按语）。
- 学习质量：学习小结新增表 2，含记忆卡保留率（复习阶段评分中非“重来”的比例）、反复重来的卡片、回顾筛选率（收藏、弃置或写按语的比例）、摘录转卡率，并与上期同期比较。小结节次相应调整为：一、数据概览；二、学习质量；三、内容分布；四、焦点进展；五、目标与达成；六、复盘；七、计划执行；附录。
- 今日功课：首页新增“今日功课”一栏，按“① 回顾 → ② 记忆卡”列出待完成数量与合计时长，一键从未完成的一步开始；回顾完成页的按钮改为“今日功课第二步：学习记忆卡”，多个牌组有卡时混合学习。
- 札记导出：学习小结右上角“导出”新增“本期札记”，把本期收藏或写过按语的摘录按出处汇总为 Markdown，含原文、位置、译文与按语，可作讲稿或论文素材。

## 3.14 已完成与待完成配色、个人成长学术版式

- 已完成与待完成统一配色：“已”（已回顾、今日已学）用松绿，“待”（待回顾、当前待学）用藤黄，数字、圆点标签、状态标记与进度条一致。首页两张任务卡各加一条“已 / 待”进度条；今日回顾顶部进度、回顾完成卡、牌组页进度环（已学与待学分两段，环内另注待学张数）、“今天还有 N 张”、学习完成页、每日学习量面板和统计页“还剩”同样处理。数量为 0 时数字转灰，颜色之外始终有文字。
- 个人成长重新编排：左侧目录分“一、回顾与总结（学习小结、成长趋势、复盘历史）”“二、计划与执行（学习计划、重复安排、难卡跟踪）”“三、成果与资料（我的成果、专题学习、资料导出）”三部分九节，右侧每节有节号、标题与一句说明；窄窗口时目录收为分组菜单。
- 学习小结改为报告体例：居中题目与周期，下分“一、数据概览（表 1 本期与上期同期比较，含增减与变化率）”“二、内容分布（表 2 按出处／专题／牌组，含序号与占比）”“三、目标与达成（表 3）”“四、复盘（4.1 收获、4.2 困难、4.3 下一步，并以引文块对照上期的下一步）”“五、计划执行”与“附录 本期明细”。表格采用三线表，表题在上、注在下；点选表 1 的一行，第二节与附录随之切换。
- 新增界面预览：另行打包的“KongReview预览”只使用内存中的示例库，用于检查界面，不读写个人学习库。

## 3.13 每日学习量：全库合计、仅今天加量与混合学习

- 新增“每日学习量”面板：牌组首页顶部按钮、牌组卡片上的“新 · 复”标签、右键菜单和“设置 → 记忆卡 → 按牌组调整…”都可打开。一处设置牌组默认值、全库合计和各牌组单独上限；数字可直接输入（0–9999），也可用步进器；面板顶部即时预览今天此刻还可学的新卡、学习中、复习张数和约需分钟数，并列出各牌组今天已学与此刻可学。保存后立即生效。
- 全库合计上限（可不设）：限制所有牌组加起来每天最多学多少新卡、复习多少张。一张卡要同时满足牌组上限和全库合计，某牌组此刻可学＝min(牌组余额, 全库余额)；合计较小时先学的牌组先用。牌组首页显示“全库每日合计：已学 / 上限”，统计页按牌组表的合计行同样显示。
- 仅今天加量：达到上限时，完成页和牌组首页提供“今天再学 10 张新卡”“今天再复习 50 张”。只在真正挡住的那一级加量——牌组上限挡住就加牌组，全库合计挡住就加合计，“全部牌组”范围按牌组名顺序补足——明天自动失效，不必再改回；可在面板里清除。加量随牌组改名转移，不写入完整备份。
- 学习全部牌组：两个以上牌组有待学卡片时，首页可混合学习；学习中、到期复习优先，再按创建先后出新卡，各牌组上限与全库合计照常生效，完成页与撤销评分以全库为范围。
- 口径统一：牌组页、首页、菜单栏、提醒、统计页均使用同一账本。首页与菜单栏的待学数改用全库队列（有合计上限时不再把各牌组数字直接相加）；未来日期的提醒按各牌组自己的上限估计，再受全库合计约束。按笔记本学习保留原设计——以牌组默认值为本笔记本的额度——但同时受全库合计约束。
- 设置与牌组选项的上限改为数字框加步进器，范围统一为 0–9999（此前全局新卡最多 500、复习最少 10）。全库合计的开关与数值随完整备份保存。

## 3.12 批量草稿、模板管理与作答对照

- 批量粘贴的原文、格式、字段对应、牌组与标签、候选修改、勾选和页码自动保存为草稿；可“保存草稿并关闭”，下次打开或重启后继续。恢复后按当前卡片和笔记类型重新检查，不沿用过期查重结果；只有明确放弃或成功保存后才清除本批草稿。
- 个人录入预设可复制，并调整自定义栏目顺序，折叠、填写提示与必填规则随栏目移动。单个或全部模板可单独导出为 JSON；导入先预览、勾选及改名，作为独立模板加入，保留已有预设与牌组绑定。缺少匹配笔记类型或字段顺序变化的项目不能导入，文件不包含卡片正文和学习数据。
- 批量候选的重复提醒旁提供“查看原卡、编辑原卡、追加答案、跳过此条”。编辑原卡前保留本批草稿；追加先选择位置并预览，成功后排除此候选，其他候选继续整理和保存。原卡已删除时先处理删除状态，保存与追加仍重新检查最新内容。
- 录入历史增加起止日期范围，显示当前学习状态、正式作答次数及适用的下次到期时间；可选择当前页卡片进行额外练习。练习使用所选卡片的独立会话，不改变正式复习排程、学习记录或每日名额。
- 正式学习与额外练习均可启用“先作答再对照”：先写自己的回答，翻面后与参考答案对照，窄窗口改为上下排列。额外练习支持本次自评；正式学习仍由原评分按钮决定排程。自己的回答只保留在当前会话，不自动判分，也不写入卡片正文。
- 摘录编辑页的原文、译文／白话和按语编辑框随内容增减高度，短文减少空白，长文由外层窗口滚动；文字与 HTML 模式继续可切换。

## 3.11 常用模板、批量录入与录入历史

- 内置“名词解释、历史事件、人物、史料分析、论述题”五类录入模板，可先查看填写示例，再复制、修改并保存到自己的预设。复制后正文为空白，示例不写入卡片；保存后可为牌组绑定默认录入模板。
- 正面、背面、多字段及自定义栏目可设置填写提示和必填规则。提示独立显示，缺少必填内容时在栏目标题旁提醒并阻止保存；必填栏目不能直接删除。规则随当前草稿保存为快照，后续修改预设不会改变已打开的输入，连续录入保留结构时沿用对应规则。
- 批量粘贴支持表格／Tab分列与“问：／答：”分组，每批最多500张。带引号的表格单元格可含换行和Tab；先指定列对应，再按每页30张检查、预览、编辑或取消勾选。非空列不能遗漏；模板、必填及正面重复在保存事务中重新检查，失败整批回滚，关闭未保存输入前确认。
- 记忆卡首页提供“今日录入”和按日期查看的“录入历史”，每页50张，可预览、编辑并整理牌组与标签，跨重启保留。从3.11起记录新建卡片，不回填旧卡，也不把导入或编辑算作新录入；删除后恢复仍归原录入日期。历史与完整备份一起保存，兼容v13、v14、v15备份。
- 本次录入清单与录入历史中的批量移动牌组、添加或移除标签，可撤销当前运行期间最近一次组织操作。撤销只恢复该次涉及的组织字段，保留无关标签、正文和学习进度；相关字段已改、卡片已删除／恢复或正在编辑时拒绝覆盖并保留撤销入口，便于处理后重试。

## 3.10 录入预设、草稿整理与牌组模板

- 常用录入结构可命名保存为预设，包含默认牌组、标签、栏目名称和折叠方式，也可引用已有多字段笔记类型。套用后生成空白问答或字段，不复制正文、媒体、卡片身份或学习进度；已有输入先保存或保留草稿，避免替换内容。
- 追加成功后可“撤销本次追加”，恢复原答案与栏目，保留此后的学习进度、牌组、标签及关联。仅撤销当前运行期间最近一次追加；原卡正文或模板已变化、删除，或正在编辑时拒绝覆盖并说明原因。
- 首页草稿列表支持关键词、摘录／记忆卡及牌组筛选，每页50份、上下页和跳页，按最近保存稳定排序。可先只读预览完整内容；卡片按当前模板排版并支持翻面，摘录包含正文、译文和按语。关闭预览保留筛选和页码，草稿更新或移除后旧预览不能恢复。
- “本次已添加”可打开分页录入清单，预览或重新编辑卡片，按当前页选择批量移动牌组、添加或移除标签。编辑前保留当前输入，保存或返回后继续刚才的草稿；批量操作只更新组织信息，不改问答及学习进度。本次清单随新一轮录入重置，正式卡片保留。
- 每个牌组可设置默认录入模板；从牌组菜单、牌组选项或卡片编辑器进入，绑定后新建卡片自动填入空白结构和标签。选择牌组时只对空白新卡应用模板；直接键入牌组后按回车应用，已有输入保留。预设与牌组绑定随完整备份保存，改名和合并牌组时同步处理绑定。

## 3.9 连续录入、返回草稿与卡片预览

- 新卡可“保存并新增”，分别选择沿用牌组、标签及空栏目／模板结构，并显示本次已添加数量；保存失败保留输入。下一张只保留所选元数据，正文、原摘录关联、Anki标识与学习进度从新卡开始。
- 重复提醒中编辑原卡后，上方可“返回本次草稿”；原卡未保存修改先持久保留，也可“保存并返回草稿”。恢复沿用原有冲突检查，原条目有变化时将输入作为新卡打开，旧内容与进度保留。
- 追加答案可勾选当前背面、自定义栏目或模板的独立答案字段，选择原卡的背面／栏目／独立答案字段；查看最终完整卡片后确认保存。相同完整片段拒绝重复追加；保存时重新核对原卡、题面、模板和预览，原卡的学习进度保留。
- 编辑器上方“预览卡片”使用学习页面相同的排版，查看未保存内容、翻面、折叠栏目、图片和链接；预览不产生学习记录。切换或保存前同步编辑器，旧会话输入不能写入返回后的草稿。

## 3.8.1 重复提示与原卡操作

- 正面重复时，红色提醒紧靠编辑区上方的“正面”标题右侧；编辑原卡、追加答案和对照入口放在同一区域，长文滚动时仍可见。窄窗口自动分行，操作仍留在上方。
- “编辑原卡”先保留当前输入为可恢复草稿，再重新读取并编辑原卡；找不到原卡、重复关系已变化或草稿无法保留时不切换。原卡的学习进度、牌组和标签保持最新值。
- “追加答案”先打开原卡与当前输入的对照预览，确认后才追加并保存，保留原答案与学习进度。最近删除中的卡片先恢复，再编辑或追加。

## 3.8 录入、长文定位与全库资料检查

- 带格式粘贴先选择保留格式、清理格式或纯文字，预览后插入当前选区，并记住下次默认选项。文字模式移除可执行的剪贴板内容，源码模式仍允许直接编辑源码；纯文本正常直接粘贴。原文／快速录入粘贴后识别末尾“正文——作者《书名》第12页（或 P.12）”，核对后填入出处表单，再正式保存；复杂格式的出处不跨标签删除。
- 每个字段提供可收起的目录与定位面板，按 H1—H6 标题跳转，支持返回顶部及打开目录前的编辑位置；文字和源码模式均可用，长文会同时滚动外层视图。
- 链接与媒体检查可预览并选择本地图片／音频／视频替换，文字模式双击图片也可进入。只改这一处引用，文件按内容生成独立名称并存进媒体表，不覆盖其他同名媒体；支持撤销，随完整备份保留。单文件最多32MB，预览不联网加载远程资源。
- 主窗口工具栏“资料检查”分批扫描正式摘录、记忆卡及模板字段、网页、专题文字、出处网址和成长记录。可暂停／继续、筛选、搜索并每页50项显示问题；处理前重读当前内容，打开原条目或所属页面修正，处理后重新检查。草稿、历史和最近删除不在本次范围，不联网测试远程资源；结果只保存在当前运行会话，重启后重新扫描。

## 3.7 查找替换、差异标记与资料检查

- 每个正文编辑器提供当前字段查找／替换，支持⌘F、区分大小写、上一处／下一处、单处替换和全部替换预览。文字模式只匹配正文，源码模式包括标签及属性；替换可撤销，预览过期后拒绝覆盖。
- 修改对照按段落标出绿色新增、红色删除、橙色改动；可切换回原排版查看图片与样式，长文采用有界区块比较。
- 格式清理可选择内联字体／字号、颜色、空段落及空span／Word标记，先查看前后排版与源码，再采用；保留语义标签、链接和媒体，代码块不自动清理。
- 链接与媒体检查显示当前字段的地址写法、页内目标、本地图片和音频是否存在；可定位并选中源码地址进行修改。远程网站及媒体不联网测试。

## 3.6 编辑检查、重复对照与正文历史

- 输入停顿后自动检查正面重复；红色提示位于“正面”标题右侧，显示重复卡片所在牌组。保存时继续执行事务检查，过期的输入检查不会覆盖新输入。
- 重复卡片可以并排查看正面、背面和出处；确认后把当前答案追加到已有卡片，保留原答案和学习进度。已有卡片变化时拒绝覆盖并提示重新对照。
- 源码模式增加 HTML 检查，提示常见引号、闭合标签、链接协议问题；修正前预览源码与文字，由用户选择采用。复杂模板与 HTML 可选闭合语法仍需人工判断。
- 编辑草稿沿用即时本机保存和重启恢复；保存前可对照当前输入与上次保存。正文修改记录最近100个版本，从本版开始留存并随完整备份保存；恢复先放回编辑器，保存后生效，保留当前牌组、标签与学习进度。
- 通过独立内存数据库与临时草稿目录的测试窗口验证真实按钮、对照、追加确认、历史恢复、HTML修正、100段长文、源码撤销、栏目独立切换和中文内容。测试窗口与个人学习库隔离。

## 3.5.4 记忆卡正面查重

新建和编辑时只比较正面，忽略大小写、全半角、HTML／Markdown 排版及多余空白，跨牌组检查；背面、栏目和标签不同也视为相同题面。提供已有卡片预览并保留当前输入。最近删除中的相同卡片提供恢复或继续新建选择，恢复保留学习进度。

模板卡比较实际显示的正面；图片和音频优先按本地媒体字节比较，未缓存的外部媒体按引用地址比较。填空卡按实际题面区分挖空位置，批量保存有重复时全部不写入。现有卡片的整理／合并仍采用完整内容比较，避免删除背面不同的资料；导入同步规则保持原有行为。

## 3.5.3 阅读链接显示

修正 HTML 链接只填写域名时，阅读界面显示 Markdown 链接文字的问题。合法域名在显示时补全 HTTPS，原始内容保持不变；源码链接应使用完整引号与 </a> 闭合标签。

## 3.5.2 文字与 HTML 双模式编辑

正文编辑区默认显示可直接编辑的文字与排版，各区域右上角提供 <> 按钮，独立切换 HTML 源码。切换前同步输入，未编辑的原始内容不改写；记忆卡、自定义栏目、填空卡、按语、快速录入与成长记录共用相同入口。源码模式保留左侧对齐修复，文字模式支持格式工具栏和挖空。

## 3.5.1 编辑器左侧显示修复

修正 HTML 源码编辑器打开及调整窗口宽度时的左侧遮挡：正文宽度随可见区域变化，保留左右边距并锁定横向位置，长文仍可纵向阅读。

## 3.5 HTML 源码编辑

- 所有正文入口统一为原生 HTML 源码编辑器，包括摘录、译文、按语、记忆卡及自定义栏目、填空卡、笔记、网页存档、快速录入、学习计划与成长小结。
- 等宽文字直接编辑标签，粘贴保留源码；工具栏插入标签，支持原生撤销、重做和长内容自适应高度。
- 旧 Markdown 打开时转换为可编辑 HTML；没有编辑时保留原始存储内容。标题、搜索、标签、页码等普通字段保持原用途。
- 填空选择避开 HTML 标签和不完整实体；正文搜索支持跨行内标签匹配，成长列表和小结导出显示正文内容。

## 3.4 重复安排、成果积累与专题问题

- **每周重复安排**：新建学习计划时按所选日期的星期每周重复，也支持多行拆分。每个安排最多保留一项待办，打开首页或计划页时检查到期任务，漏做多周只保留最近应做的一次，不逐周补建；旧待办仍在时不再生成新任务。可跳过本次、暂停或恢复重复，恢复从下一个重复日期开始，已有任务和历史不删除；编辑单次任务不改变后续规则。
- **我的成果**：个人成长中集中展示已完成计划填写的收获或关联成果，支持繁简搜索、完成日期和专题筛选，每页50条，长文可展开，关联原文删除时仍保留收获。可补充收获，返回时保留筛选、页码和位置。专题采用现有资料关联，不将同一专题中的多次引用重复计数。
- **月／年复盘引导**：结合已有学习统计，汇总完成计划、成果和已解决专题问题，提示填写理解加深、未解决问题、下一阶段关注；提供本期成果和专题问题入口，相关统计与引导也加入月／年小结 Markdown。数字整理记录，不自动评价理解程度。
- **专题问题与解答**：专题页增加“问题与解答”，记录疑问、补充解释并关联摘录／文字笔记／记忆卡。填写答案后可标为解决，也可重新打开。支持搜索、分页、长文阅读、未保存草稿恢复和状态冲突保护；问题按当前解决状态与解决日期计入小结。
- **完整性与验证**：重复游标、问题、草稿和成果随完整备份恢复；恢复后不重复生成待办。覆盖漏做、跳过、暂停恢复、夏令时、成果筛选、105条分页、长答案、完成撤销与首页入口回归，并检查新页面窄窗口布局。独立窗口原生按钮与编辑器检查再次尝试后仍缺少图形会话／辅助功能树，明确保留为未验证项。

## 3.3 学习安排、收获与每周复盘

- **今日学习安排**：首页设置今天想回顾的摘录条数、学习的记忆卡张数，按今日去重记录显示进度，并连接今日回顾与记忆卡首页。与每日小结共用目标；0表示不设目标，目标不改变原学习排程。下方仍可分页查看今日及逾期计划。
- **完成计划与收获**：标为完成时可选填收获，关联一条摘录或笔记本文字笔记，确认后一起保存；已完成计划可补充收获且保留原完成日期。未确认输入自动暂存，再次打开同一计划的完成／收获窗口即可继续。状态冲突不会覆盖其他操作，可保留输入并重新读取状态；关联原文删除后保留收获。
- **小结里的成果**：已完成计划与收获自动进入对应日／周／月／年小结，Markdown导出也包含所有分页的计划收获及关联资料标题。
- **每周复盘引导**：周小结对照上周的下一步，分页查看当周完成、取消和当前待处理计划。可继续、调整日期或放下，保留本周每项计划最近一次处理决定；继续安排到所选周下一周，复盘旧周最早安排到今天。依据当前计划状态，不还原过去的待办状态。
- **专题成长轨迹**：专题学习中切换时间轨迹，按50条分页查看新增摘录、笔记／按语最近修改、关联计划完成及收获。卡片内容修改从3.3起保留修改时的专题归属与标题，排程／移动牌组不产生记录，原卡删除后轨迹仍保留；旧版未记录过的修改不能追补。
- **稳定性完善**：长文字可展开阅读；专题选择、轨迹页码与阅读位置保留，资料减少自动修正末页。完整备份包含目标、收获草稿、周复盘决定及专题轨迹；恢复后旧页面不能继续写入恢复前内容。
- **验证边界**：使用独立测试数据验证，不读取个人学习库。命令行宿主无法驱动原生按钮点击，相关检查明确跳过，未计为通过。

## 3.2 今日待办与学习追溯

- **计划拆分与今日待办**：复盘的“下一步”可按行拆成多条计划，保存前可核对数量、共同日期及关联资料。首页展示今日／逾期数量，按5条翻页，直接打开资料或完成计划；计划页支持改期、取消及恢复，取消记录保留但不计入完成小结。
- **草稿保护**：未保存的计划输入、拆分选择和资料关联自动暂存到数据库。切换页面、重启或备份恢复后，在学习计划的“未保存草稿”继续；丢弃前确认，编辑遇到状态冲突时保留输入，不覆盖新的完成状态。
- **难卡内容对照**：先保存处理原因，此后编辑原卡内容会自动保留每次修改的前后快照并开始观察。排程和移动牌组不产生内容快照；历史分页保留，旧版本没有保存过的内容无法追补。
- **拆分卡关联**：可将已创建的拆分卡关联到原难卡，分页查看各自跟踪期内的评分、重来次数；移除关联不删除卡片，原卡删除后保留处理历史。不同问题分别统计，不混为一个改善比例。
- **小结追溯**：选择回顾摘录、学习卡片、评分、难卡或新增资料指标，按出处／专题汇总；卡片指标还可按牌组汇总，再点开该组的分页明细。采用当前归属；专题内重复引用不重复计算，跨专题允许重叠并明确提示。
- **连续使用**：成长模块记住栏目、周期及日期，计划／复盘／难卡列表保留页码；阅读面板返回列表恢复原页及位置。数据减少时自动修正页码，恢复备份时清除旧库的导航状态。

## 3.1 趋势、复盘与学习行动

- **成长趋势**：近30天／12周／12个月，分别查看回顾摘录、学习卡片和评分次数；按对应周期去重，点击柱形或日期选择打开50条一页的明细。
- **复盘历史**：按日／周／月／年筛选，繁简搜索收获、困难和下一步，分页查看历史小结；打开小结可对照上一周期的下一步。
- **学习计划**：把复盘“下一步”转为计划，设置日期并关联笔记本、出处或记忆卡，也可独立新建。待完成／已完成分页展示，支持编辑、完成及撤销完成；按完成时间归入日／周／月／年小结。计划点击保存后生效，原文复盘仍保留。
- **困难卡处理跟踪**：记录需要拆分、补背景、暂缓处理等原因；先编辑卡片，再手动开始跟踪。比较开始前后等长时段（最长14天）的正式评分次数、重来次数及比例；前后不足3次评分提示样本不足，手动标记解决或恢复观察。暂缓仅作标记，不改变学习排程；拆出的卡片独立统计。
- 计划与难卡处理记录随数据库和完整备份保存；关联内容删除后保留记录。使用原有成长存储结构，兼容上一版完整备份。

## 3.0 个人成长与专题学习

- **日／周／月／年小结**：侧栏“个人成长”统一展示回顾摘录、学习卡片、评分次数、难卡、新增资料和学习天数。数字可点开50条一页的明细；已结束周期对比上一完整周期，进行中的周期对比上一周期相同日数与时间。统计反映学习记录，不推断能力分数。
- **目标与个人复盘**：各周期可独立设置摘录、卡片目标，填写收获、困难、下一步；自动保存到数据库，支持小结 Markdown 导出，随完整备份迁移。新增资料统计只包含仍在库中的创建记录；永久删除后无法补算。
- **专题学习总览**：使用已有专题笔记本，汇总去重摘录、关联卡片、出处及有学习次数记录的卡片；分页打开资料，继续阅读、回顾或学习。笔记本中也可展开总览。
- **转卡先预览**：单条摘录“做成记忆卡”打开预填编辑器，先调整问答、牌组、标签并核对已有卡，保存才创建；保留草稿恢复与内容查重。
- **专题／出处学习资料导出**：在成长模块“资料导出”或专题页选择 Markdown／PDF，勾选原文译文、按语笔记、卡片问答和出处。PDF按文字讲义排版，不执行资料脚本或加载远程资源；媒体请另用完整备份。
- **跨重启扫描**：相似卡每批持久保存游标和建议，显示剩余卡数；重新打开后点“继续上次扫描”。恢复时核对范围内卡片及更新时间，新增、修改、删除或学习状态变化时安全重扫，避免过期进度遗漏内容。
- **升级兼容**：新增成长与进度存储表；仍可校验和恢复2.8／2.9完整备份，恢复后自动升级，并保留恢复前安全备份。

## 2.9 查找、追溯与继续学习

- **关键词定位**：全局搜索高亮命中词，点击结果进入阅读定位面板，自动滚动到首个命中段落，可上一处／下一处浏览；支持繁简和长段落。可再打开原条目编辑或查看原网页格式。
- **学习记录日历**：统计页、记忆卡首页和热力图日期可打开指定日期的全部操作与评分，按50条分页。原条目已删除时仍保留记录并标明，历史记录打开的是当前内容。
- **难卡集中练习**：记忆卡首页按近30天至少3次“重来”筛选，可选牌组，查看问答、原摘录并进入编辑。额外练习不写评分、不影响正常排程；正式评分仍从牌组开始。
- **资料关联**：摘录编辑面板显示关联卡数量和分页列表；摘录右键或回顾页脑形图标可打开关联卡，再查看原摘录和出处。再次制作已有卡片的摘录时先展示已有卡，不重复创建。
- **全库相似扫描**：所选范围按批次遍历，无最近5000张或4000字正文限制；可在窗口内暂停、比较、继续。每批最多32对，积累约200组建议后暂停，可整理或清空本批建议后继续；关闭窗口结束会话。新增或修改卡片后重新扫描，保留人工确认、备份与撤销。

## 2.8 备份、搜索与资料整理

- **完整备份与恢复**：设置 → 数据可导出单个完整备份文件，包含数据库、已存入应用的图片和音频、网页缓存、草稿及可迁移设置。恢复前校验并预览数量，确认后先保存当前资料的安全备份；失败自动回滚。外部同步目录和未存档的远程资源不包含在内。
- **后台统计**：首页与记忆卡统计在后台从同一数据库快照计算，复用学习记录和牌组数据，只读取排程字段；连续刷新合并，过期结果不覆盖当前范围。
- **全局搜索**：⌘⇧F 同时查找摘录、记忆卡、网页与出处，分类分页展示，点击打开完整内容；支持繁简通搜，排除最近删除内容。
- **批量标签与筛选**：牌组浏览支持标签和学习状态筛选；选中当前页卡片可批量添加、移除标签，支持撤销，保留后续学习进度和其他标签变动。
- **相似卡提示**：查重面板增加相似卡模式和牌组范围，比较正反面后手选保留项，确认才整理，并保留学习记录。每次扫描所选范围最近 5000 张，跳过规范化后超过 4000 字的正文，界面说明扫描范围；提示不代表内容一定重复。

## 2.7 回顾与学习衔接

- **回顾草稿保护**：回顾里的按语和就地编辑逐次保存，切换摘录、范围、菜单或重启后可继续；也能从首页草稿列表恢复到完整编辑面板。保存时核对正在编辑的字段，保留最新收藏、标签与回顾进度；原内容已改变或删除时保留草稿并提示处理。放弃草稿需明确确认。
- **统计口径统一**：首页、回顾完成页与统计页使用相同的每日去重学习记录，条数、张数、评分次数分开显示。记忆卡完成页显示当前牌组或笔记本的统计，并另列全库今日记录；明天到期只计算明天当天，累计操作次数也明确标注。
- **撤销记忆卡评分**：学习页“撤销评分”或 ⌘Z 撤销最近一次评分，恢复评分前排程、返回原卡答案，并移除对应评分记录，使统计与每日名额同步恢复。卡片已改动、删除或再次评分时拒绝覆盖；编辑面板打开时不占用文字撤销快捷键。
- **长摘录阅读定位**：按日期、回顾范围和摘录记住滚动位置，新摘录从顶部开始、返回已读摘录恢复位置；点击按语自动定位编辑区，保存或收起后回到阅读位置，网页正文逐步加载时继续恢复。
- **待学状态说明**：首页、牌组总览及学习结束页区分达到每日上限、学习中稍后到期、未来排程、全部暂停和没有卡片，显示下一次可学时间。学习中的卡可提前 20 分钟，限额或等待不再误显示为全部完成；牌组已学张数不再换算可能重复的完成百分比。

## 2.5 编辑、浏览与整理

- **草稿自动恢复**：摘录、记忆卡的未保存修改独立保存在本机。首页显示待恢复草稿，可继续编辑或明确放弃；取消编辑可选保留草稿、放弃修改或继续。保存成功后只清理对应草稿；原条目已更新、删除或学习进度已变化时恢复为新条目，并显示原因。失效出处关联会解除，已删除版本的未保存页码保留在按语中。
- **分页设置与位置记忆**：摘录菜单、网页存档、出处管理和牌组浏览可选每页 50／100／200 条；按菜单、出处或牌组分别记住搜索、筛选、页码和排序。编辑后定位原条目，重新打开恢复浏览参数；翻页或改变条件仍清空多选。
- **网页阅读进度与查找**：每篇文章记住阅读位置，结合段落锚点和图片布局恢复。阅读器内按 ⌘F 查找，支持上一处、下一处和命中数；查找标记不改正文、摘录高亮或用户选区。网页列表新增存档时间、标题和未读优先排序。
- **记忆卡固定格式工具栏**：工具栏留在编辑面板顶部，标明当前字段；正反面、多字段及背面栏目仍随内容调整高度。选择文字后点工具栏保留选区，链接输入也留在顶部。
- **已有记忆卡查重整理**：记忆卡首页“查重”扫描全库，逐组并排比较牌组、标签、内容和学习进度；手选保留项并确认后才整理。首次处理前备份，保留卡完全不写，其他卡软删除并保留历史，可撤销。整理前重读完整快照，卡片已编辑或学习时要求重新扫描；不同多字段内容不会误并。

## 2.4 新增与修复

- **首页**：侧边栏第一项为“首页”，启动直接显示回顾、记忆卡、库存、篇目进度等完整统计；统计下方有“去学习记忆卡·数量”和“去今日回顾·数量”。学习入口直接进入上次尚未学完的牌组，或待学最多的牌组；学过记忆卡不会让未完成的摘录回顾被误计为零。
- **侧边栏品牌信息**：底部固定显示现有应用 logo、开发者孔祥瑞和安装版本号。
- **摘录分页**：“全部摘录”“未归类”每页 200 条，支持上一页、下一页和页码跳转；搜索、筛选后回到第一页。分页查询在数据库队列执行，列表只解析长文预览，避免长文本拖慢操作；编辑与导出始终使用完整正文。
- **编辑原文与长文操作**：点击编辑按摘录编号重新取完整原文。编辑器脚本就绪即可操作，不再等待图片下载；原文、译文、按语和记忆卡字段使用固定编辑区内滚动，工具栏始终留在编辑区顶部。

回顾时：空格 = 下一条，← = 上一条，F = 收藏，M = 加入记忆卡，Delete = 弃置，E = 编辑，1–4 = 给记忆卡打分。

## 构建

### 方式一：只打包 DMG（不需要安装 Xcode）

只需要 Apple 命令行工具（`xcode-select --install`）：

```bash
./Tools/build-dmg.sh        # 产物在仓库同级目录：../KongReview-<版本>.dmg
```

用的是本机 ad-hoc 签名，没有公证。第一次打开时，如果系统提示“无法验证开发者”，在访达中右键点 KongReview →“打开”即可；或者到“系统设置 → 隐私与安全性”里点“仍要打开”。

### 方式二：用 Xcode 开发

需要 Xcode 16 或更新版本，系统要求 macOS 14 以上。

```bash
brew install xcodegen          # 首次使用时安装
cd KongReview
xcodegen generate              # 根据 project.yml 生成 KongReview.xcodeproj
open KongReview.xcodeproj
```

在 Xcode 中选 KongReview 目标 → Signing & Capabilities → Team 选自己的 Apple ID，然后按 ⌘R 运行。

`.xcodeproj` 不进版本库，每次改了 `project.yml` 或新增了文件，重新执行 `xcodegen generate` 即可。

核心逻辑（回顾算法、链接解析、导出）放在独立的 Swift 包里，可以脱离 Xcode 单独测试：

```bash
cd Packages/KongReviewCore && swift test
```

数据库层（表结构、全文检索、标签查询、捕获入库）和 `LibraryStore` 的测试在 `KongReviewTests/` 里，在 Xcode 中按 ⌘U 运行。

> 2.4 开发验证使用 macOS、Swift 6.4 与 GRDB 7.11.1，包含完整 SwiftUI 应用编译、核心逻辑和数据库回归测试；图形会话相关测试的执行情况以测试报告为准。

## 网页摘录

**书签小程序**：打开“设置 → 摘录 → 复制书签代码”，在浏览器里新建一个书签，把代码粘贴到网址栏。阅读网页时选中文字，点这个书签，KongReview 就会弹出新建面板，标题和网址已经填好，补上标签后保存。

> 如果在 Safari 中点书签没有反应：先在 Safari 设置 → 高级 中勾选“显示网页开发者功能”，再到“开发”菜单启用“允许来自智能搜索栏的 JavaScript”。第一次跳转时浏览器会询问是否允许打开 KongReview，选允许即可。

**链接格式**，可供快捷指令、kongfetch、Alfred 等工具调用：

```
kongreview://add?text=学而时习之&title=论语&author=&url=&location=学而第一&tags=论语,学
```

参数需要做 URL 编码。`text` 为必填项。

## 数据

全部数据保存在一个 SQLite 文件中：

```
~/Library/Application Support/KongReview/kongreview.sqlite
```

在“设置 → 数据”里可以直接在访达中打开这个位置。备份时复制整个文件夹即可。
