# KongReview

个人用的 macOS 摘录与回顾工具。思路参照 Readwise：把读书、读网页时的摘录集中起来，每天随机推送几条，让旧摘录重新出现在眼前。

属于 kong 系列应用（kongflow · kongbabel · kongvox · kongfetch）。0.6 起由 KongGlean 更名为 KongReview：首次启动会自动把旧版的数据和设置复制过来，旧链接 `kongglean://` 继续可用。

## 2.4.1 首页与今日回顾

- **首页日课卡**：采用回顾完成页的简洁版式，显示日期、今日回顾与记忆卡次数、连续回顾天数、待学卡片、近 7 天柱状图和今日一句；底部并排放“去学习记忆卡”和“去今日回顾”，都附实际待办数量。完整统计继续从侧边栏“回顾统计”打开。
- **今日回顾直接进入当天队列**：侧边栏、应用菜单、菜单栏和 `kongreview://review` 统一打开全库的当天回顾，退出按书、标签或笔记本的旧范围；未完成时接着上次进度，完成后显示今日回顾统计，不自动从头开始或重新抽取。

## 2.4 新增与修复

- **首页**：侧边栏第一项为“首页”，启动直接显示回顾、记忆卡、库存、篇目进度等完整统计；统计下方有“去学习记忆卡·数量”和“去今日回顾·数量”。学习入口直接进入上次尚未学完的牌组，或待学最多的牌组；学过记忆卡不会让未完成的摘录回顾被误计为零。
- **侧边栏品牌信息**：底部固定显示现有应用 logo、开发者孔祥瑞和安装版本号。
- **摘录分页**：“全部摘录”“未归类”每页 200 条，支持上一页、下一页和页码跳转；搜索、筛选后回到第一页。分页查询在数据库队列执行，列表只解析长文预览，避免长文本拖慢操作；编辑与导出始终使用完整正文。
- **编辑原文与长文操作**：点击编辑按摘录编号重新取完整原文。编辑器脚本就绪即可操作，不再等待图片下载；原文、译文、按语和记忆卡字段使用固定编辑区内滚动，工具栏始终留在编辑区顶部。
- **禁止重复手工卡片**：新增或编辑记忆卡时，跨牌组检查正反面组合；忽略首尾空白，不把正在编辑的原卡误判为重复。重复时保留输入草稿并提示修改。
- **Anki 媒体保护**：不同包内同名但内容不同的图片、音频会自动生成新文件名并更新本次导入引用，保留旧卡媒体；内容相同的媒体复用。
- **整理数据库保护图片**：统一识别 Markdown、HTML、音频、本地媒体地址及卡片字段、栏目中的引用；原摘录彻底删除后仍被卡片使用的图片不会误删。
- **牌组改名保留设置**：每日上限、FSRS 与保留率随牌组名一起迁移；合并进已有牌组时采用目标牌组配置。
- **同名出处完整导出**：“全部导出”自动为同名、文件名清理后重名以及大小写重名的出处生成唯一文件名，也避开“未归类.md”。
- **网页正文及时刷新**：保存修改后的存档正文立即刷新阅读器，并重新应用摘录标记。

开发验证：根目录 `swift test` 运行数据库与应用状态测试，`swift test --package-path Packages/KongReviewCore` 运行核心逻辑测试。WebKit 编辑器交互测试需要已登录的 macOS 图形会话，无图形会话时明确跳过。

## 2.3 新增

- **记忆卡按牌组的统计**：统计页新增“记忆卡：按牌组”表，可切换“今天 / 最近 7 天”。今天：每个牌组新卡学了几张 / 每日上限、复习几张 / 上限、评分几次、“重来”几次、答对率，以及“还剩”（即牌组页此刻显示的新卡 · 学习中 · 待复习），底部有合计。新卡、复习按“张”算，分法与每日上限完全相同，可以直接核对牌组页的数字：上限 − 已学 = 牌组页显示的数（不超过实际到期的张数）。

## 2.2 新增

- **修正：复习后牌组页的数字不变**。原因是“今天学了几张新卡、几张复习”的判断：以前只看这张卡今天之前有没有回答记录，从 Anki 导入的旧卡在本应用里没有记录，第一次复习就被算成“新卡”——占掉当天的新卡名额（新卡显示 0，其实一张没学），复习名额却不减，待复习的数字也就不跟着变。现在每次回答都记下回答前的卡片状态；旧记录按“今天之前没有回答、且复习次数不超过今天的回答次数”判断。另外牌组页每次打开、停留期间每分钟都按当前时间重算，统计页打开时也重算。
- **从对照表导入版本页码**：出处书页“导入版本页码…”，选对照的版本，选一个 Excel（.xlsx）、CSV 文件，或在 Excel 里选中几列复制后点“从剪贴板粘贴”。表的每行写“原页码 → 该版页码”，可加一列篇名区分同页不同篇，原页码可写范围（3-5）；第一行是表头、多出备注列都没关系。导入前预览能对上几条、对不上几条，默认不覆盖已经填过的。
- **统计页的古籍篇目进度**：每部设了古籍体例的书一块：几篇、全篇回顾过几篇、摘录回顾过多少；一排小格子每格一篇，颜色越深回顾得越全；下面写最近一周回顾了哪些篇。点开是这部书的篇目进度面板。

## 2.1 新增

- **篇目进度**：出处书页“按篇”菜单里每篇都标出“12 条 · 回顾 8 · 卡 5”，全部回顾过的打 ✓；新增“篇目进度…”面板，逐篇一条书脊色进度条（回顾过几成）、做成记忆卡几条，每篇可直接“回顾”“做卡”，一眼看出哪篇还没过。
- **同一古籍的不同版本**：同一部古籍有几个出处（如《论语译注》《论语集释》都设了原典书名“论语”）时，编辑摘录多出“其他版本的页码”，记下这条在各版本里的页码；专题笔记本“导出”菜单里为每部古籍选“出注用的版本”（按笔记本记住），Word、PDF、演示稿、Markdown、复制的脚注和参考文献表都改用该版本——篇名沿用原位置，页码换成该版的：《论语·学而》，程树德：《论语集释》，北京：中华书局，1990年，第5页。还没有该版页码的条目照原出处引用，并在引文核对里列为“缺所选版本的页码”，可直接在清单里补。

## 2.0 新增

- **按篇回顾、按篇做卡**：出处书页新增“按篇”菜单——按摘录位置里的篇名（“学而第一”记作“学而”；只有卷次时按卷）把一本书分篇，按书中顺序列出各篇及条数；每篇可“回顾这一篇”（今日回顾里按页码过一遍），或“做成记忆卡”（牌组“论语::学而”，古籍用原典书名）。今日回顾的范围菜单显示“按篇回顾 ·《论语·学而》”。
- **引文核对里直接补页码**：核对清单中“缺页码”的每条右边有页码框，填 12 或 12-15，按 Tab 到下一条；点“保存页码”（或回车）一次写进各条摘录——接在原位置后面写成“学而第一 · 第3页”，可 ⌘Z 撤销——然后自动重新核对；从导出进来的，补齐后接着导出。

## 1.9 新增

- **引文核对**：专题笔记本导出 Word 或 PDF 前，自动检查每条引文——没有出处、缺页码（网页、人工智能内容不要求；直接引原典而不注版本的古籍也不要求）、按古籍体例却缺篇名、同一部书卷次写法不统一（“卷七”“卷7”“第七卷”混用，以多数为准）、书籍出处缺出版者或年份。有问题时列出清单，点“修改”直接打开那条摘录或那个出处，也可“仍然导出”；“导出”菜单里也能单独“引文核对…”。
- **记忆卡的原文语境**：由摘录做成的卡片，显示答案后点卡片右上角的“原文语境”（或按 C），在背面下方看到同一本书里按页码排在前后的各两条摘录，这一条用浅蓝底标出；展开或收起会记住。
- **日课卡提醒**：每天的提醒通知改为“日课 · 十月十五日 · 星期四”，正文写今天的摘录条数、记忆卡张数（新 / 学习中 / 复习）、约需几分钟，以及昨天看了多少、已连续几天；最近两天的通知附一张纸色日课卡小图（朱印“日课”）。

## 1.8 新增

- **编辑记忆卡：编辑器高度随内容**：正面、背面和各栏目的编辑框按实际内容的高短显示，内容少就矮、多了自动变高，删减后也会缩回（以前取的是网页视图本身的高度，只会变高、缩不回去，还会沿用上一张卡留下的高度）。
- **学习界面书斋风**：卡片左侧一道牌组的传统色书脊，牌组名宋体、上级名小字；字词、短句之类的短正面居中放大；正反面之间一枚“答”字小印；背面栏目名用楷体赭色；评分按钮的色点改为朱砂（重来）、藤黄（困难）、石青（良好）、松绿（简单）；学完盖“日课已毕”，附“温故而知新，可以为师矣”。
- **一年来的功课**：记忆卡首页新增复习热力图，每格一天、每列一周，颜色取当天复习最多的牌组的书脊色，深浅表示次数；显示过去一年学了多少天、复习多少次、连续几天；鼠标停在格子上看当天详情。
- **古籍“卷”的写法与常用古籍**：位置里有“卷七”这样的卷次时，脚注写成“（汉）司马迁：《史记》卷七《项羽本纪》，北京：中华书局，1959年，第300页。”；编辑出处的“常用古籍”菜单可直接选《论语》《史记》《资治通鉴》《日知录》等，出处就是原典本身且作者空着时，顺带填上习惯标注的朝代与作者。

## 1.7 新增

- **记忆卡首页重新设计**：顶部“今日功课”——还剩多少张、新卡 / 学习中 / 待复习各多少、约需几分钟，右侧进度环显示今天已复习的张数，“开始复习”一键进入上次学的（或待学最多的）牌组；全部学完时盖“日课已毕”朱印。牌组改为卡片网格：书脊取传统色（石青、朱砂、松绿、藤黄……，同一上级牌组同色），宋体牌组名，“论语::学而第一”分两行显示上级与本级，三项计数，熟练度条（熟记 / 生疏 / 学习中 / 新卡，熟记按 Anki 的定义为间隔 ≥ 21 天），今天学完的牌组盖“今日已毕”印章；双击开始学习。
- **专题笔记本 ↔ 记忆卡**：笔记本工具栏新增“记忆卡”菜单：把笔记本里的摘录做成问答卡，放进以笔记本命名的牌组（已有卡片的不重复做）；逐条做填空卡（依次打开挖空面板，可跳过，已做过的自动略过）；只学习这本笔记本的卡片（不论在哪个牌组）。
- **古籍篇章引用体例**：出处可设“原典书名”，脚注写成“《论语·学而》”；注本、整理本接着写整理本信息：《论语·学而》，杨伯峻：《论语译注》，北京：中华书局，1980年，第3页。篇名取摘录位置（“学而第一”记作“学而”）。记忆卡背面、引文速查、Word / PDF 脚注一致；GB/T 7714 不受影响。
- **按书回顾**：出处书页“回顾这本书”，在今日回顾里按页码从头过一遍。
- **按页码范围批量**：出处书页“按页码…”，选第几页到第几页：回顾这一段、做成记忆卡、导出这一段的读书笔记，或选中后批量加标签、移出处、加入笔记本。

## 1.6 新增

- **出处书页**：点侧边栏的出处，列表上方显示书页头——封面、作者、出版者、年份，摘录条数、页码范围、回顾过、有按语、记忆卡、收藏各多少；摘录默认按页码排列（取位置里的第一个数字，没有页码的排在最后），可切换为按录入时间；“导出读书笔记”把这本书的全部摘录按页码排好，附位置与按语，导出 Word 或 Markdown。
- **搜索语法**：搜索框里可直接写条件，空格分隔、任意组合：多个词同时出现；`"整句"`；`-排除词`；`出处:论语`、`作者:杨伯峻`；`标签:儒家` 或 `#儒家`；`页:12-30`；`有按语`、`有译文`、`收藏`、`记忆卡`。摘录列表、引文速查、专题笔记本的插入摘录面板都能用，仍是繁简通搜。
- **专题笔记本导出 PDF**：版式与 Word 版一致（宋体小四、1.5 倍行距、黑体标题、楷体引文段、目录），页眉为标题、页脚居中页码；网页排版做不到页脚注，出处改为每节末尾的节末注（①②）。
- **LiquidText 批注**：按 2026 年 10 月 14 日带批注的实际导出核对：工作区里单独的批注列在导出文件最后，不标明属于哪条摘录（“Refers to a comment”），导入为同一本书下带“批注”标签的一条。

## 1.5 新增

- **重复摘录整理**：文件 →“查找重复摘录…”。完全重复（繁简、空格、标点、Markdown 标记不计，文字相同，跨出处也算）与相似（同一出处里多几个字或断句不同；用三字片段的最小哈希分桶找候选，2.5 万条也只需数秒）分组列出，点选要保留的一条后合并：其余几条的按语、标签、收藏、回顾次数、弃置状态并入，记忆卡、回顾记录、导入记录、专题笔记本里的引用改指向保留的那条，其余移入“最近删除”。默认保留收藏过的、有按语的、有位置的那条；“合并全部完全重复”一键处理；“不是重复”以后不再提示。合并前自动备份，⌘Z 可撤销。
- **演讲者备注**：专题笔记本导出演示稿时，摘录的按语与本文批注放进该页的演讲者备注（附出处），投影上只有引文；PowerPoint、Keynote 的演示者视图里可见。
- **本文批注**：专题笔记本里的每条摘录可加“本文批注”，只属于这本笔记本，不改原摘录的按语；导出 Word 时排在引文后（“按：”），导出演示稿时进演讲者备注，Markdown / 剪贴板同样带上。
- **久未回顾**：回顾统计页新增“久未回顾”——从未在每日回顾中出现过、半年以上没出现过的摘录各有多少、哪些出处最多；“本周优先回顾这些”把今日回顾的范围改为只从这些摘录里抽（回顾页顶部范围菜单也可选）。

## 1.4 新增

- **Word 导出补齐学术版式**：专题笔记本导出的 Word 增加目录（按小标题，TOC 域；Word 打开时提示更新即填上页码）、页眉（标题，下有细线）、页脚居中页码；可选附上摘录的按语（“按：”起头的评注段，楷体引文之后、灰色小字）。

- **按专题笔记本回顾**：今日回顾的范围菜单新增“专题回顾（按笔记本）”，按笔记本中的顺序把其中的摘录全部过一遍（去重、跳过已删除）；笔记本工具栏也有“回顾这本”。

- **网页存档**：侧边栏“网页存档”→ 存档网页（⌘L），粘贴网址；或在浏览器里点“整页存档”书签。KongReview 用浏览器内核打开网页，用 Mozilla Readability 提取正文（自动去掉导航、侧栏、评论、页脚），保存一份副本。
- **在应用里阅读、划线**：选中文字后按 H（或点浮出的“摘录”按钮）即存为摘录，出处自动带上标题、作者、网站、发布年份和网址；已摘录的句子在正文里以黄色标出，点击可编辑按语、标签。
- 删除存档只删正文，摘录保留。

## 0.3 新增

- **从 Readwise 导入**：菜单“文件 → 从 Readwise 导入 CSV…”或“设置 → 数据”。先显示预览（摘录数、出处数），确认后导入；导入前自动备份；同名出处合并，重复摘录跳过；Readwise 的收藏会转为 KongReview 的收藏，页码 / Kindle 位置、标签、按语、划线时间都会保留。

## 0.2 新增

- **快速录入浮窗**：在任何应用里按 ⌃⌥K（可在设置里改），弹出小窗；剪贴板有新内容时自动填入，出处默认沿用上一次。⌘↩ 保存，Esc 取消，焦点自动回到原来的应用。
- **菜单栏图标**、**登录时启动**：关掉主窗口后仍在后台运行。
- **每日自动备份**：每天第一次启动时备份一次，保留 30 份，可选存到 iCloud 云盘；也可以手动“立即备份”。
- **最近删除**：删除改为移入“最近删除”，30 天内可恢复；删除出处、清空最近删除前都会确认。
- **链接直达浮窗**：`kongreview://add`、`kongreview://quick`、`kongreview://review`；Drafts、kongfetch 的配置方法见 [docs/INTEGRATIONS.md](docs/INTEGRATIONS.md)。
- **构建不覆盖旧包**：DMG 生成在仓库同级目录，上一次的产物自动移到“KongReview旧构建/时间”。

## 基本功能

| 模块 | 说明 |
|---|---|
| 摘录 | 原文、译文 / 白话、按语、位置（页码、卷次）、标签 |
| 出处 | 书籍、论文、网页、PDF；作者、出版者、版本、年份、网址；可单独调整回顾频率 |
| 每日回顾 | 按概率抽取，摘录多的书出现得多；刚出现过的摘录降权；同一天内重开应用看到的是同一组 |
| 记忆卡 | 半衰期 1 / 7 / 14 / 28 天，回忆概率降到 50% 时排进当日回顾 |
| 主题回顾 | 按标签限定回顾范围 |
| 搜索 | SQLite FTS5 trigram 全文检索，可搜中文任意子串；不足 3 字时自动改用模糊匹配 |
| 网页摘录 | 浏览器书签小程序 + `kongreview://add?...` 链接 |
| 导出 | Markdown（带 YAML 头，适合 Obsidian）；复制时附带中文引文 |
| 提醒 | 每日定时本地通知 |

快捷键：⌃⌥K 快速录入（全局），⌘N 新建摘录，⌥⌘N 快速录入浮窗，⇧⌘N 新建出处，⇧⌘R 今日回顾，⇧⌘E 全部导出。
回顾时：空格 = 下一条，← = 上一条，F = 收藏，M = 加入记忆卡，Delete = 弃置，E = 编辑，1–4 = 给记忆卡打分。

## 构建

### 方式一：只打包 DMG（不需要安装 Xcode）

只需要 Apple 命令行工具（`xcode-select --install`）：

```bash
./Tools/build-dmg.sh        # 产物在仓库同级目录：../KongReview-<版本>.dmg
```

用的是本机 ad-hoc 签名，没有公证。第一次打开时，如果系统提示“无法验证开发者”，在访达中右键点 KongReview →“打开”即可；或者到“系统设置 → 隐私与安全性”里点“仍要打开”。

### 方式二：用 Xcode 开发

需要 Xcode 16 或更新版本，系统要求 macOS 14 以上。

```bash
brew install xcodegen          # 首次使用时安装
cd KongReview
xcodegen generate              # 根据 project.yml 生成 KongReview.xcodeproj
open KongReview.xcodeproj
```

在 Xcode 中选 KongReview 目标 → Signing & Capabilities → Team 选自己的 Apple ID，然后按 ⌘R 运行。

`.xcodeproj` 不进版本库，每次改了 `project.yml` 或新增了文件，重新执行 `xcodegen generate` 即可。

核心逻辑（回顾算法、链接解析、导出）放在独立的 Swift 包里，可以脱离 Xcode 单独测试：

```bash
cd Packages/KongReviewCore && swift test
```

数据库层（表结构、全文检索、标签查询、捕获入库）和 `LibraryStore` 的测试在 `KongReviewTests/` 里，在 Xcode 中按 ⌘U 运行。

> 2.4 开发验证使用 macOS、Swift 6.4 与 GRDB 7.11.1，包含完整 SwiftUI 应用编译、核心逻辑和数据库回归测试；图形会话相关测试的执行情况以测试报告为准。

## 网页摘录

**书签小程序**：打开“设置 → 摘录 → 复制书签代码”，在浏览器里新建一个书签，把代码粘贴到网址栏。阅读网页时选中文字，点这个书签，KongReview 就会弹出新建面板，标题和网址已经填好，补上标签后保存。

> 如果在 Safari 中点书签没有反应：先在 Safari 设置 → 高级 中勾选“显示网页开发者功能”，再到“开发”菜单启用“允许来自智能搜索栏的 JavaScript”。第一次跳转时浏览器会询问是否允许打开 KongReview，选允许即可。

**链接格式**，可供快捷指令、kongfetch、Alfred 等工具调用：

```
kongreview://add?text=学而时习之&title=论语&author=&url=&location=学而第一&tags=论语,学
```

参数需要做 URL 编码。`text` 为必填项。

## 数据

全部数据保存在一个 SQLite 文件中：

```
~/Library/Application Support/KongReview/kongreview.sqlite
```

在“设置 → 数据”里可以直接在访达中打开这个位置。备份时复制整个文件夹即可。
