# KongReview

个人用的 macOS 摘录与回顾工具。思路参照 Readwise：把读书、读网页时的摘录集中起来，每天随机推送几条，让旧摘录重新出现在眼前。

属于 kong 系列应用（kongflow · kongbabel · kongvox · kongfetch）。0.6 起由 KongGlean 更名为 KongReview：首次启动会自动把旧版的数据和设置复制过来，旧链接 `kongglean://` 继续可用。

## 1.4 新增

- **Word 导出补齐学术版式**：专题笔记本导出的 Word 增加目录（按小标题，TOC 域；Word 打开时提示更新即填上页码）、页眉（标题，下有细线）、页脚居中页码；可选附上摘录的按语（“按：”起头的评注段，楷体引文之后、灰色小字）。
- **导出演示稿**：专题笔记本 → PowerPoint（.pptx，Keynote 也能打开），16:9 纸色版式：封面（标题、日期）、小标题做章节页、每条摘录一页（左侧蓝色竖条、宋体大字、右下角出处，字多时自动缩小字号，特别长的按句子拆页并标页次）、文字做正文页、可选按语框与参考文献页。
- **按专题笔记本回顾**：今日回顾的范围菜单新增“专题回顾（按笔记本）”，按笔记本中的顺序把其中的摘录全部过一遍（去重、跳过已删除）；笔记本工具栏也有“回顾这本”。

## 1.3 新增

- **专题笔记本**：侧边栏“专题笔记本”，把摘录与自己的文字编排成一篇长文（讲稿、论文草稿、专题综述）。由摘录、文字、小标题三种块组成：两块之间点“＋”插入，拖动左侧把手或 ↑↓ 调整顺序，删除可 ⌘Z 撤销；摘录块显示摘录的最新文字与出处。摘录右键、批量操作、回顾卡片的分享菜单都可“加入专题笔记本”。导出：Word（.docx，出处为真脚注，①②编号每页重新起编；宋体小四、1.5 倍行距、首行缩进，摘录为楷体引文段）、Markdown（`[^1]` 脚注）、复制到剪贴板粘进 Word / Pages（RTF 脚注）；可选文末附 GB/T 7714 参考文献表。
- **系统“服务”菜单**：在任何应用里选中文字 → 右键 →“服务”→“添加到 KongReview”，打开快速录入浮窗并填好正文（保留格式）；浏览器里自动填网址与网页标题，其他应用（预览、Word、Pages……）取窗口标题作出处（需辅助功能权限）。另有“在 KongReview 中查引文”，以选中文字为关键词打开引文速查。
- **快速录入浮窗所见即所得**：正文改为与主窗口相同的编辑器，快捷键、行首 Markdown、粘贴保留格式都可用；Tab / ⇧Tab 仍在各栏之间切换。
- **每周小结**：每周第一次打开今日回顾时，顶部显示上周（周一至周日）的回顾摘录数、记忆卡次数与答对率、新增摘录、有回顾的天数，以及“本周金句”（上周收藏或回顾过的一条）；已允许通知时，周一 8 点后推送一条。可在“设置 → 回顾”关闭。
- **手形光标**：改为在各个按钮上直接设置（1.2 的统一判断方式在没有开启辅助功能客户端时识别不到 SwiftUI 按钮），回顾页的胶囊按钮、卡片图标、链接、菜单都显示手形。
- **回顾页顶栏**：范围选择改为胶囊菜单，窗口较窄时右侧的统计依次收起，不再被截断。

## 1.2 新增

- **所见即所得编辑**：摘录原文、译文、按语，回顾按语，记忆卡正反面与填空卡附加内容，都改为所见即所得的编辑框，不再显示 Markdown 符号，也去掉了下方的预览。快捷键 ⌘B 粗体、⌘I 斜体、⇧⌘X 删除线、⌘E 行内代码、⌘K 链接、⌘1/⌘2/⌘3 标题、⌘0 正文、⇧⌘8 列表、⇧⌘7 编号列表、⇧⌘. 引用；也可直接敲 Markdown（行首“# ”“- ”“1. ”“> ”，**粗体**、*斜体*、`代码`、~~删除~~），敲完即变。保存的仍是 Markdown（记忆卡原来是 HTML 的保持 HTML），与以前的数据、导出完全兼容。
- **粘贴保留格式**：从网页、Word、Pages、Anki 粘贴时保留标题、粗体、斜体、删除线、列表、引用、链接、网络图片，去掉字体、字号、颜色；快速录入浮窗粘贴、自动填入剪贴板时也把格式转成 Markdown。
- **记忆卡背面栏目**：背面可添加多个自定义栏目（释义、出处、例句……），可改名、排序、删除、设为默认折叠；复习、搜索、导出 .apkg 都包含栏目。
- **繁简通搜**：搜索索引按繁简归一（字表取自 OpenCC），“红卫兵”“紅衛兵”互相能搜到；记忆卡搜索、引文速查、搜索词标黄、相关摘录同样适用。原文不改动。
- **LiquidText 自动导入**：“设置 → 数据”指定一个文件夹，LiquidText 把笔记导出到这里即自动导入（启动、回到前台和每分钟检查一次）。每条摘录记“出处 + 页码 + 原文”的来源键：同一本书重新导出时只导入新摘的，在 KongReview 里改过或删掉的不会被加回来。
- **回顾时就地编辑**：按 E 在卡片上直接改原文、译文、按语（⌥E 仍打开编辑面板）；摘录已做成记忆卡时按设置同步或询问。
- **写作**：引文速查按 Tab 多选、一次粘贴；新格式“原文 + 脚注”把出处做成 Word / Pages 的真脚注（剪贴板放 RTF）；摘录列表“导出 → 参考文献表”与出处管理右键可按 GB/T 7714—2015 生成参考文献表（顺序编码制或著者-出版年制）。
- **手形光标**：鼠标移到按钮、链接、复选框、弹出菜单上显示手形光标（“设置 → 快速录入”下方可关闭）。

## 1.1 新增

- **LiquidText 导入**：文件 →“从 LiquidText 导入笔记…”（⇧⌘I），选 LiquidText 导出的 Word 笔记（.docx，可多选）或纯文本；也可从剪贴板导入。按实际导出文件归纳格式：每条笔记“Excerpt: 正文 / (文档名 , p.页码)”，出处与页码逐条取出，“书名(作者)”自动拆分；图片摘录连同图片导入（存进数据库，回顾时显示）；PDF 换行留下的中文空格自动去掉；批注并入上一条摘录的按语。同一页的同一段文字视为重复，不同页的同样文字（如只摘了人名）各算一条；可选择跳过很短的摘录。
- **标签整理**：标签可用“/”分层（#儒家/孟子），侧边栏按层级显示、父标签包含子标签；右键改名、合并、删除（子标签、已存搜索同步更新，可 ⌘Z 撤销）；“整理标签”面板提示只差大小写、全半角的重复标签。
- **记忆卡负荷与保留率**：统计页新增未来 30 天每日到期量（过期计入今天，显示 7 日均值与高峰日）与每周实际保留率曲线（只算隔天以上的复习），并画出 FSRS 期望保留率目标线。
- **性能**：统计页与模板编辑器改为 SQL 计数，不再读出全部卡片；分享图只在点“分享”时渲染；引文速查输入防抖 150 毫秒。
- **侧边栏收紧**：默认宽度 240 → 196 点，字号、行高、计数字号都小一号。

## 1.0 新增

- **性能**：用 2.5 万条摘录、5 千张卡、2 万条回顾记录实测，把每次重绘都要读全部日志的统计（约 0.2 秒）改为数据变化时用 SQL 按日汇总一次（约 0.04 秒），牌组计数同样改为缓存，界面直接读。
- **从备份恢复**：设置 → 数据 →“从备份恢复…”，列出本机与 iCloud 的全部备份（日期、摘录数、卡片数、大小）；恢复前自动另存当前数据；用 SQLite 在线备份写回，无需重启。
- **撤销 / 重做**：回顾时的弃置、收藏，删除摘录、批量操作、合并或删除出处、删除记忆卡、调整回顾频率，都可 ⌘Z 撤销、⇧⌘Z 重做。
- **引文速查浮窗**（默认 ⌃⌥L）：在任何应用里搜索摘录，回车把“原文 + 出处”粘到光标处；四种粘贴格式；自动粘贴需辅助功能权限，否则自动复制。
- **相关摘录**：回顾卡片下方展开（R），按用词相近（汉字两字组 TF-IDF）+ 同标签 + 同出处列出最相关的几条。
- **问题排查**：出错与关键操作写入日志；“帮助 → 导出诊断信息…”生成不含摘录正文的诊断文件；使用说明里新增“试用一周的检查清单”。

## 0.9 新增

- **填空卡**：摘录右键或回顾时按 C →“做成填空卡”。在原文里选中字词点“挖空”（⌘D），每个编号生成一张卡，只遮住这一处；“同卡再挖”（⇧⌘D）在同一张卡里遮住几处。背面自动附上译文、按语与出处。
- **出处封面**：编辑出处时可把封面图拖进来、选择图片，或填 ISBN 从 Open Library 获取；封面显示在回顾卡片、分享图上（缩成长边 600 像素的 JPEG 存在数据库里）。
- **单条摘录的回顾频率**：回顾卡片右下角或右键“回顾频率”：多出现（×2.5）、正常、少出现（×0.35）、不再出现。
- **分享图**：把一条摘录生成 1080×1350 的竖版图片（纸色或夜色，可附译文、按语，带封面与出处），可复制、存 PNG 或直接分享。
- **组合筛选与已存搜索**：列表工具栏“筛选”：出处、多个标签（须同时具备）、日期（近 7 / 30 天、近一年或自定义）、只看收藏；搜索词在结果里标黄；“保存为搜索”存到侧边栏“已存搜索”。
- **自动同步到 Obsidian**：设置 → 数据：选一个文件夹（建议 Obsidian 库里的子文件夹），摘录有改动 3 秒后自动更新对应出处的 Markdown 文件，只写有变化的文件。
- **收件箱**：其他应用（计划中的 PDF 批注应用、脚本）把摘录写成 JSON 放进收件箱文件夹即自动导入；格式见 [docs/INTEGRATIONS.md](docs/INTEGRATIONS.md)。

## 0.8 新增

- **卡片模板（多字段笔记）**：从 Anki 导入的多字段笔记保留每个字段（如《论语》卡片的正文、注释、译文、解题、备注）。在“记忆卡 → 卡片模板”为每个字段选择“正面 / 背面 / 背面·折叠 / 不显示”，实时预览；注释、备注这类字段默认折叠。已导入过的卡重新导入同一个包即可补上字段（不重复建卡、不动复习进度）。
- **FSRS 排程**：实现 FSRS-6（与 Anki 25.x 内置版本同一套公式与默认参数，已与 py-fsrs 6.3.2 逐步对照）。每个牌组可选 SM-2 或 FSRS，并设期望记忆保留率；导入 Anki 包时沿用它的 FSRS 设置、每张卡的记忆状态（稳定性、难度）与复习记录。“设置 → 记忆卡 → 用我的复习记录优化”按自己的记录拟合参数（留出 1/5 记录做检验，确实更准才采用）。
- **每个牌组单独设上限**：右键牌组 → 牌组选项：每天新卡、复习上限（不设则跟随全局）、算法、保留率。
- **导出到 Anki（.apkg）**：选牌组导出，可带复习进度、FSRS 记忆状态与复习记录；在 AnkiMobile / AnkiDroid / Anki 桌面版导入即可在手机上复习。导出的包已用 Anki 26.09 官方引擎实际导入验证。
- **摘录 ↔ 记忆卡联动**：改了已做成卡的摘录，询问是否同步卡片内容（可设为总是 / 从不）；学习、编辑、浏览卡片时可一键打开原摘录。
- **深色模式**：自动调亮卡片自带的深灰色文字、去掉浅色底色（可关闭）。
- **所见即所得的显示**：回顾页的原文、译文、按语与编辑时的预览改用网页内核渲染，Markdown 标题真正放大、列表缩进、图片显示，与记忆卡同一套样式；打字时预览只替换内容、不闪烁。
- **整理数据库**：“设置 → 数据”显示各部分占用，一键删除没有卡片再用到的图片并 VACUUM（整理前自动备份）。
- **不开主窗口也能看进度**：菜单栏图标旁显示“今日待看摘录·待学卡片”（如 8·23），菜单里也有；每日提醒写明当天的摘录条数与记忆卡数。

## 0.7 新增

- **记忆卡（仿 Anki）**：侧边栏“记忆卡”独立成页。牌组列表显示新卡 / 学习中 / 待复习；“学习”先看正面，空格显示答案，按 1 重来、2 困难、3 良好、4 简单（显示答案后空格 = 良好），按钮上标出下次间隔；E 编辑当前卡。排程与 Anki 默认设置一致（SM-2：学习步长 1 分钟、10 分钟，毕业 1 天，简单 4 天，起始难度系数 250%，最低 130%）。“浏览”可搜索、编辑、暂停 / 恢复、移到别的牌组、删除。卡片正反面支持 Markdown 或 HTML、图片。
- **导入 Anki**：记忆卡页工具栏或“文件 → 导入 Anki 牌组…”。支持 `.apkg` 牌组包、`.colpkg` 集合包（新旧格式都能读：新格式的 zstd 压缩由内置的纯 Swift 解压器处理）与“纯文本笔记”导出的 `.txt`（识别 `#separator`、`#deck column` 等文件头）。保留牌组、标签、图片（只导入笔记里用到的）、填空题，`.apkg` 里的复习进度（间隔、难度、到期日）一并沿用；同一笔记重复导入会跳过；导入前自动备份。
- 摘录“做成记忆卡”（右键、批量、回顾时按 M）：正面原文，背面译文、按语、出处。原来的“加入记忆卡”自动转成牌组“摘录”里的卡片。
- **回顾时写按语**：按 N 在当前摘录下写评论，⌘↩ 保存。
- **回顾快捷键**：下一条 空格 / → / J，上一条 ← / K，收藏 F，弃置 Delete，编辑 E。写按语时单键快捷键自动停用。
- **回顾统计**：首页（今日回顾）顶部常驻统计条——今日回顾数、连续天数、近 7 天柱形、记忆卡待学；侧边栏“回顾统计”为完整页面：今天、连续天数、最长连续、累计、记忆卡正确率，最近 30 天柱状图，库存数字。
- **提醒与回顾挂钩**：当天看过一条摘录或复习过一张卡，就不再提醒（逐日排单次通知，回顾后撤掉当天那条）。
- **跨日自动换新**：应用开着过夜，第二天回顾自动换成新的一组（跨日、唤醒、回到前台时检查）。
- **存档网页自动填网址**：自动读取 Safari / Chrome / Edge / Brave / Arc 当前标签页（第一次会询问是否允许控制浏览器）；读不到时用剪贴板。
- **编辑存档正文**：阅读器工具栏“编辑正文”，可改 HTML，或整段换成 Markdown。摘录的原文、译文、按语支持 Markdown 行内格式。
- **图片显示修复**：存档里的图片经本地代理加载并缓存（处理 http 图片、懒加载 `data-src`、防盗链 Referer），离线也能看。
- 侧边栏“出处”默认折叠；新建出处可选类型“人工智能”（引文标注“人工智能生成内容”）；菜单栏“设置…”可正常打开。

## 0.5 新增

- **大库流畅**：摘录列表分页加载（每次 200 条，滚到底自动续载），2 万条也不卡。
- **批量操作**：列表里 ⌘ / ⇧ 多选（⌘A 全选），右键或工具栏“批量操作”：加标签、去标签、移到出处、收藏、加入记忆卡、弃置、删除。
- **出处管理**（侧边栏）：表格列出全部出处，可按书名、作者、类型、摘录数、添加时间排序；“只看疑似重复”找出同名出处；多选后合并（保留哪一个由你选，合并前自动备份）、批量改类型、删除。侧边栏出处列表可按最近添加 / 摘录数 / 书名排序。
- **专题汇编**：任何列表（某标签、某出处、搜索结果或所选摘录）→ 导出 → 专题汇编，生成 Word（A4、宋体小四、1.5 倍行距、首行缩进两字）或 Markdown，按出处分组或按时间排列，每条附引文。
- **导出到 Anki**：生成 Anki 可直接导入的文本文件（正面原文，背面译文、按语、出处；标签随行）。
- **引文体例**：中文脚注体例 / GB/T 7714—2015 两种可选（设置 → 摘录）；出处新增“出版地”“期刊/文集名”“卷期”字段。

## 0.4 新增

- **网页存档**：侧边栏“网页存档”→ 存档网页（⌘L），粘贴网址；或在浏览器里点“整页存档”书签。KongReview 用浏览器内核打开网页，用 Mozilla Readability 提取正文（自动去掉导航、侧栏、评论、页脚），保存一份副本。
- **在应用里阅读、划线**：选中文字后按 H（或点浮出的“摘录”按钮）即存为摘录，出处自动带上标题、作者、网站、发布年份和网址；已摘录的句子在正文里以黄色标出，点击可编辑按语、标签。
- 删除存档只删正文，摘录保留。

## 0.3 新增

- **从 Readwise 导入**：菜单“文件 → 从 Readwise 导入 CSV…”或“设置 → 数据”。先显示预览（摘录数、出处数），确认后导入；导入前自动备份；同名出处合并，重复摘录跳过；Readwise 的收藏会转为 KongReview 的收藏，页码 / Kindle 位置、标签、按语、划线时间都会保留。

## 0.2 新增

- **快速录入浮窗**：在任何应用里按 ⌃⌥K（可在设置里改），弹出小窗；剪贴板有新内容时自动填入，出处默认沿用上一次。⌘↩ 保存，Esc 取消，焦点自动回到原来的应用。
- **菜单栏图标**、**登录时启动**：关掉主窗口后仍在后台运行。
- **每日自动备份**：每天第一次启动时备份一次，保留 30 份，可选存到 iCloud 云盘；也可以手动“立即备份”。
- **最近删除**：删除改为移入“最近删除”，30 天内可恢复；删除出处、清空最近删除前都会确认。
- **链接直达浮窗**：`kongreview://add`、`kongreview://quick`、`kongreview://review`；Drafts、kongfetch 的配置方法见 [docs/INTEGRATIONS.md](docs/INTEGRATIONS.md)。
- **构建不覆盖旧包**：DMG 生成在仓库同级目录，上一次的产物自动移到“KongReview旧构建/时间”。

## 基本功能

| 模块 | 说明 |
|---|---|
| 摘录 | 原文、译文 / 白话、按语、位置（页码、卷次）、标签 |
| 出处 | 书籍、论文、网页、PDF；作者、出版者、版本、年份、网址；可单独调整回顾频率 |
| 每日回顾 | 按概率抽取，摘录多的书出现得多；刚出现过的摘录降权；同一天内重开应用看到的是同一组 |
| 记忆卡 | 半衰期 1 / 7 / 14 / 28 天，回忆概率降到 50% 时排进当日回顾 |
| 主题回顾 | 按标签限定回顾范围 |
| 搜索 | SQLite FTS5 trigram 全文检索，可搜中文任意子串；不足 3 字时自动改用模糊匹配 |
| 网页摘录 | 浏览器书签小程序 + `kongreview://add?...` 链接 |
| 导出 | Markdown（带 YAML 头，适合 Obsidian）；复制时附带中文引文 |
| 提醒 | 每日定时本地通知 |

快捷键：⌃⌥K 快速录入（全局），⌘N 新建摘录，⌥⌘N 快速录入浮窗，⇧⌘N 新建出处，⇧⌘R 今日回顾，⇧⌘E 全部导出。
回顾时：空格 = 下一条，← = 上一条，F = 收藏，M = 加入记忆卡，Delete = 弃置，E = 编辑，1–4 = 给记忆卡打分。

## 构建

### 方式一：只打包 DMG（不需要安装 Xcode）

只需要 Apple 命令行工具（`xcode-select --install`）：

```bash
./Tools/build-dmg.sh        # 产物在仓库同级目录：../KongReview-<版本>.dmg
```

用的是本机 ad-hoc 签名，没有公证。第一次打开时，如果系统提示“无法验证开发者”，在访达中右键点 KongReview →“打开”即可；或者到“系统设置 → 隐私与安全性”里点“仍要打开”。

### 方式二：用 Xcode 开发

需要 Xcode 16 或更新版本，系统要求 macOS 14 以上。

```bash
brew install xcodegen          # 首次使用时安装
cd KongReview
xcodegen generate              # 根据 project.yml 生成 KongReview.xcodeproj
open KongReview.xcodeproj
```

在 Xcode 中选 KongReview 目标 → Signing & Capabilities → Team 选自己的 Apple ID，然后按 ⌘R 运行。

`.xcodeproj` 不进版本库，每次改了 `project.yml` 或新增了文件，重新执行 `xcodegen generate` 即可。

核心逻辑（回顾算法、链接解析、导出）放在独立的 Swift 包里，可以脱离 Xcode 单独测试：

```bash
cd Packages/KongReviewCore && swift test
```

数据库层（表结构、全文检索、标签查询、捕获入库）和 `LibraryStore` 的测试在 `KongReviewTests/` 里，在 Xcode 中按 ⌘U 运行。

> 开发状态：`KongReviewCore`、`AppDatabase`、`LibraryStore` 已用 Swift 6.0.3 + GRDB 7.8 编译，测试全部通过（Linux 环境）。SwiftUI 界面部分尚未在 Xcode 中编译过，第一次构建时可能需要修正少量编译问题。

## 网页摘录

**书签小程序**：打开“设置 → 摘录 → 复制书签代码”，在浏览器里新建一个书签，把代码粘贴到网址栏。阅读网页时选中文字，点这个书签，KongReview 就会弹出新建面板，标题和网址已经填好，补上标签后保存。

> 如果在 Safari 中点书签没有反应：先在 Safari 设置 → 高级 中勾选“显示网页开发者功能”，再到“开发”菜单启用“允许来自智能搜索栏的 JavaScript”。第一次跳转时浏览器会询问是否允许打开 KongReview，选允许即可。

**链接格式**，可供快捷指令、kongfetch、Alfred 等工具调用：

```
kongreview://add?text=学而时习之&title=论语&author=&url=&location=学而第一&tags=论语,学
```

参数需要做 URL 编码。`text` 为必填项。

## 数据

全部数据保存在一个 SQLite 文件中：

```
~/Library/Application Support/KongReview/kongreview.sqlite
```

在“设置 → 数据”里可以直接在访达中打开这个位置。备份时复制整个文件夹即可。
